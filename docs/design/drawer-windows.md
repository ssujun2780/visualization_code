# 서랍 표시 영역과 연결 강조

2026-11-11 사용자 요청에 따른 구현 계약. 원본 실행과 분리된 표시 설정이며 생성 모델·추론기는 변경하지 않습니다.

- D-01 기본 크기는 기존 그대로 유지합니다. 배열·힙·구조체 및 중첩 서랍의 우하단 모서리 드래그 또는 선택 후 Shift+방향키로 폭/높이를 지정합니다. 일반 방향키는 기존 화면 이동입니다. 재생 중 조작 때문에 자동 정지하지 않습니다.
- D-02 지정한 크기에 들어가는 완전한 원소/멤버 상자만 표시합니다. 가린 원소의 논리 ID와 참조는 유지하고 서랍 대표점으로 연결합니다. 부모/자식 서랍 크기와 접기 상태는 각각 유지합니다. 시점 이동에도 크기를 유지하고 배치 초기화에서 기본값으로 복원합니다.
- D-03 확대 시 현재 시점의 자료형·기록된 바이트로 추가 칸을 만듭니다. 미관측 값·미초기화 값은 미확정 상태를 유지합니다. 최종 객체 장부의 값을 과거로 가져오거나, 추가 C 읽기/명령을 실행하지 않습니다. 원본 객체·할당·수명·순서는 그대로입니다.
- D-04 표시 폭은 210~4096, 높이는 132~4096 월드 단위입니다. 객체 하나에 추가 생성하는 미리보기는 최대 2048칸입니다. 큰 미접근 배열 전체를 순회하지 않습니다. 크기 조절은 시작 부분의 표시량을 바꾸며 임의 위치로 이동하는 내부 스크롤은 이번 범위가 아닙니다. 원래 관측/참조한 칸은 여전히 ID를 유지합니다.
- D-05 선택·호버·현재 연산의 대상에서 실제 포인터 간선을 양방향으로 따라간 연결 성분을 강조합니다. 다중 포인터와 별칭·순환을 포함합니다. 같은 컨테이너에 속하거나 접혀서 같은 대표점을 쓰는 것만으로 연결을 합치지 않습니다. 현재 시점의 간선만 사용합니다.
- D-06 상태/값 보존, 확대·축소 시 가시성, 숨김/복원 후 정확한 연결점, 중첩/접기/시점 이동, 미래 WRITE 미노출, 대규모 할당의 표시 한도, 순환·별칭·포함 경계를 관련 검사와 실제 화면에서 구별해 확인합니다.
