# 구조 변화와 공통 표시 이력

2026-11-14 사용자 승인 구현 범위입니다. PS-02·06, SS-01~04와 기존 다섯 명령의 사건 시간선을 유지합니다. 중간언어·자료구조/실행 관계 추론기를 변경하지 않습니다. 실제 브라우저의 검증 완료 여부는 별도 [대응표](../validation/structure-transitions.md)를 확인합니다.

## ST-01 원본 사실과 변화 기록

기존 준비 결과의 연속 관계를 논리 노드 ID·원본 범위로 비교하여 구성원, 연결, 색·높이·확인된 상태·키 범위의 변화를 기록합니다. 원본 사건 ID와 경계 인덱스를 보관합니다. 이력 없음/생략은 확인된 삭제·복사·회전으로 승격하지 않습니다. 같은 값은 같은 원소나 복사의 근거가 아닙니다.

색·높이·상태 범위는 최종 선택 노드뿐 아니라 관측된 중간 노드까지 수집하고 해당 범위 WRITE를 준비 경계에 포함합니다. 값 이동은 기존 dataFlowForEvent의 실제 생산자·복사·범위 출처를 계속 사용합니다. 새 명령·메모리 접근을 만들지 않습니다. 회전·분할·병합의 이름·원인 설명을 새로 추론하거나 알고리즘 이름을 판별하지 않습니다.

## ST-02 안정된 시점별 배치

종류·정체성·원본 소속과 물리 배열/인덱스 힙 슬롯은 고정합니다. 포인터 기반 계층은 현재 노드·간선·루트에서 좌표를 준비합니다. 깊이가 같고 관계가 그대로인 가지와 독립 트리의 자리를 보존하고 변경 노드의 겹침만 조정합니다. 색 변경은 배치를 바꾸지 않습니다. 여러 WRITE 도중 순환·다중 부모가 생기면 기존 위치에서 실제 연결을 표시하고, 임의로 정상 트리를 완성하지 않습니다.

배열 내부 노드는 내부 좌표 이력을 사용합니다. 노드마다 별도 저장소인 경우 원본 전체 범위에 해당하는 위치를 기존 필드 안에 적용합니다. 위치 적용 경계도 표시 journal에 저장하여 탐색 순서와 분리합니다. 사용자가 고정한 좌표는 우선하며, 수동 이동 때문에 기본 이력을 재생성하지 않습니다. 전체 구조의 최적 배치나 임의 고정 좌표 사이의 가독성을 보장하지 않습니다.

## ST-03 기존 시간선에서의 연출

색·상태·실제 연결의 반영은 기존 WRITE valueReady / 그 밖의 effectReady 경계를 따릅니다. 반영 이후 기존 hold 구간 중 최대 900ms를 사용해 이전·현재 좌표/색을 보간합니다. 0.25~10배속과 재생 위치에 같은 함수로 대응합니다. 캐릭터·새 사건·명령 재정렬은 추가하지 않습니다.

그리기·클릭 범위·구조 간선·값 전달·원본 포트는 같은 보간 기하를 사용합니다. 지속 포인터는 저장된 backbone을 보존하고 이동한 끝점의 짧은 직교 연결부만 따라갑니다. 애니메이션 프레임에서 native 배선기를 실행하지 않습니다. 이동 중 연결부의 최적 회피/교차 없음은 보장하지 않으며, 명령 경계의 완성 배선은 기존 장애물 회피 결과를 사용합니다. 사라진 연결을 잠시 표시할 때는 흐린 점선과 ‘이전 연결’ 표지를 사용하며 현재 참조로 조회하지 않습니다.

## ST-04 속성·상태·범위의 구분

노드 내부는 확인된 red/black 속성색과 R/B 표지를 표시합니다. 방문·대기·확정 등 명시적으로 제공된 상태는 외곽 띠와 문자로 표시합니다. 현재 접근과 선택의 강조는 별도로 유지합니다. READ만으로 방문 완료를 만들지 않습니다. 확인된 실제 다중 셀 접근은 범위 괄호로 연결합니다.

다중 키 표현은 확인된 keyRanges/keyRange의 키와 관리 필드를 별도 줄로 배치합니다. 모든 원본 셀과 연결점을 보존합니다. 역할을 모르면 기존 원본 필드를 유지하고 키 역할 미확정으로 남깁니다. 색·높이·방문 값의 역할 매핑 자체와 사용자 역할 편집 UI는 추론/설정 측 계약이며 이번 구현은 제공된 결과의 소비자입니다.

## ST-05 검증과 비용

같은 기록·설정의 정상/스킵/되돌리기 결과를 비교하며, 중간 상태·미확정·중복 값·수동 고정·개별 할당·물리 슬롯을 검사합니다. 관련 공통 경로만 실행합니다. 표시 이력은 준비된 경계마다 저장하고 동일 배치 항목은 공유합니다. 최악의 대규모 시간·메모리, 모든 알고리즘의 작업 의미 추론, 1배속 가독성 완료는 코드 검사만으로 주장하지 않습니다.
