# C 시각화 모델 중간 저장 — 2026-11-03

## 확정 원칙

- 목적은 사람이 이해할 수 있는 코드 실행 애니메이션용 중간언어입니다.
- 작업은 SPACE·READ·CALC·WRITE·FLOW 다섯 기본 형식의 조합으로 설명합니다. 사소한 연출 차이는 이후 표지로 구분합니다.
- AST·LLVM과 소스 위치를 연결하고 컴파일러 정보를 우선 사용합니다. 원문은 누락된 위치 정보와 표시 범위에만 제한적으로 조회합니다.
- 선언·초기화는 소스 작업 순서를 유지합니다. 한 순수 계산식은 CALC 하나이며, C의 자료형·폭·부호·단락 평가·부수 효과는 보존합니다.
- 숫자·상수·주소 계산은 같은 CALC를 사용합니다. 기계적인 주소 환산은 내부 관찰 정보로 보존합니다.
- 라이브러리의 실제 입출력과 메모리 효과를 기록합니다. 호출의 의미·인자·대상·반환을 유지하며 내부 구현 전체를 펼치지는 않습니다.
- 예제의 문제는 기존 공통 모델에 필요한 기능을 추가·수정하는 방식으로 반영합니다. 검사는 변경의 직접 영향 범위로 제한합니다.

- No11: No10과 함께 사전 예상과 실행 기록을 비교했으며 그 검토 범위에서 추가 보완점은 없었습니다. No10 수정 후 No11을 다시 실행하지는 않았습니다.
- 다음 검토 대상은 No12입니다.

## 저장된 기능

- 소스 위치·AST 계산 묶음·분기 원인·호출·수명·C 자료형 연결.
- 링크된 WASM 스칼라 메모리 접근과 실제 WASI 입출력 바이트 관찰.
- 공개 기록에 반영되지 않은 원시 관찰을 확인하는 집계.
- 포인터 거리의 원소 수·바이트 차이·원소 크기 정보와 one-past 상태.
- 편집 중 컴파일 진단과 한국어 메시지, 공통 브라우저 도구 준비 코드.

애니메이션은 더미입니다. 원소·바이트 표시 선택, 박스 바이트 표시와 Shift+클릭 용량 합계, 단계 실행·시점 이동 화면은 후속 작업입니다. 메모리·라이브러리·포인터 출처의 지원 범위는 [공통 모델](c-model.md)을 따릅니다.
