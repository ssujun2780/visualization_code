# 반복 묶음과 건너뛰기

2026-11-11. 사용자가 지금 구현하도록 승인한 재생 목록·탐색 기능입니다. 중간언어 생성 모델, 자료구조 추론기, 실행 관계 추론기는 변경하지 않습니다. [실행 관계 설계](execution-relations.md)의 R-02·R-03·R-04와 기존 [재생 조작](ui.md)을 따릅니다.

## L-01 반복의 근거와 정체성

컴파일러가 제공한 ForStmt·WhileStmt·DoStmt의 관계·소스 범위, 기록된 조건 판정과 반복 복귀를 사용합니다. C 원문을 파싱하거나 변수명·숫자·함수명으로 판정하지 않습니다. 같은 반복문이라도 호출 프레임과 다시 진입한 실행을 구별하고, 각 실행에서 1번째·2번째…로 셉니다. 반복 변수의 값 자체를 반복 번호로 쓰지 않습니다.

애니메이션 API는 기존 컴파일 결과의 AST에서 `navigation` 범위 정보를 별도로 만듭니다. 프로그램 ID가 일치하는 정보만 소비하고 plan·trace는 변경하지 않습니다. 기존 AST 노드가 있으면 재사용하며, 원문은 AST 끝 토큰의 누락된 길이를 확인할 때만 기존 위치 변환기를 통해 읽습니다. 상수 조건으로 FLOW가 제거된 `do-while(0)`도 관측된 본문을 이 범위에 연결합니다. 과거 저장 기록은 기존 스코프·statementSource를 사용하며, 반복 범위 근거가 없으면 평면 표시합니다.

## L-02 내부 순서 보존

목록을 접는 것은 표시만 바꾸며 내부 사건의 순서·값·생성/해제·함수 호출은 유지합니다. for·while은 조건을 준비하는 READ/CALC부터 본문·증감·반복 복귀까지 한 반복에 포함합니다. for 초기화와 두 종류의 마지막 거짓 조건은 별도로 남깁니다. do-while은 본문부터 뒤의 조건 준비·판정까지 한 반복에 포함하므로 마지막 거짓 조건도 그 반복 안에 둡니다. 실제로 실행되지 않은 반복이나 제거된 조건 사건을 만들지 않습니다.

조건 없는 for 및 상수 참 조건은 관측된 본문 범위·복귀·continue/break/return을 사용합니다. for에 중괄호가 없고 첫 본문과 초기화 경계를 나눌 메타데이터가 부족하면 첫 묶음을 ‘초기 준비 포함’으로 표시합니다. 정확한 경계를 증명하지 못한 구간을 임의로 코드 해석해서 보충하지 않습니다.

## L-03 중첩과 호출

내부 반복문은 종류와 관계없이 해당 바깥 반복 안에 표시하고, 호출된 함수의 사건도 호출한 반복에 포함합니다. 각 재귀 호출의 반복 번호는 독립적입니다. continue는 해당 반복의 증감/조건/복귀까지, break·return은 실제로 실행한 경계까지만 포함합니다.

## L-04 펼치기와 탐색

for·while·do-while 묶음 아래 반복별 행을 표시합니다. 반복을 펼치면 실제 중간언어 행을 볼 수 있고, 펼치기·접기 자체는 재생을 멈추지 않습니다. 접힌 현재 반복의 제목을 강조하며 재생이 강제로 펼치지 않습니다. 내부 행은 펼칠 때 생성해 긴 목록의 초기 DOM을 줄입니다.

각 반복 행의 ‘건너뛰기’는 그 반복 끝으로 이동합니다. 하단 ‘반복 건너뛰기’는 **1·5·10·50·100회·전체**를 제공합니다. 현재 가장 안쪽 반복문 실행에만 적용하고 진행 중인 반복의 남은 부분을 1회로 셉니다. 횟수가 남은 반복 이상이거나 전체를 누르면, 마지막 거짓 조건과 정리를 포함해 해당 반복문을 빠져나오는 기록 경계까지 이동합니다. 예를 들어 총 49회인 반복의 처음에서 100회를 누르면 49회 후 지점까지만 이동합니다. 중첩된 바깥 반복이나 같은 반복문의 다음 호출로 넘어가지 않습니다.

반복문 초기 준비에서 누르면 초기 준비와 지정한 반복을 함께 반영하고, 마지막 종료 판정만 남았으면 그 판정까지 마칩니다. 반복문 안이 아니면 하단 버튼은 비활성입니다. 미완료 실행은 현재 관측한 기록 끝까지만 이동하며, 표시 횟수가 미래의 전체 반복 수를 뜻하지 않습니다. 바깥 반복의 개별 이동은 해당 행의 버튼을 사용합니다.

## L-05 상태와 중단 경계

건너뛰기는 기존 seek/applyEvent로 중간의 값·출력·호출·정리 효과를 모두 반영하며 C를 다시 실행하지 않습니다. 재생 중이면 이동 후 재생을 유지하고, 일시정지 중이면 정지를 유지합니다. 기록되지 않은 미래 실행은 건너뛰지 않습니다. 관측 구간 끝에서 실제 입력을 기다리거나 ERROR에 도달하면 기존 중단 규칙을 유지합니다.

객체·필드·도구 배치와 지속 포인터선도 [PS-06](prepared-scene.md)에 따른 같은 표시 이력을 사용합니다. 탐색으로 중간 렌더링을 생략했음을 이유로 목적지의 배치·통로 슬롯·꺾임을 새로 결정하지 않습니다. 준비되지 않은 지점은 Worker의 표시 이력 준비가 끝난 뒤 보여 줍니다.

## L-06 검증 범위

세 종류의 혼합 중첩·재귀·재진입, continue/break, 조건식 내 함수 호출, 0회·빈 본문·상수 조건·조건 없는 반복, 감소하는 반복 변수, 입력 대기의 미완료 묶음, ERROR를 검사합니다. 건너뛴 장면의 상태는 같은 위치까지 정상 애니메이션을 진행한 상태와 비교합니다. 원본 기록 불변도 확인합니다. API 검사와 실제 목록 조작 확인을 별도로 기록합니다. [for 최초 검증](../validation/loop-navigation.md), [while·do-while 확장 검증](../validation/while-navigation.md)을 구별합니다.
