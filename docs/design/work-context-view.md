# 현재 작업 연결 보기

2026-11-13: 아래는 과거 별도 패널의 구현 기록입니다. 현재 기본 화면은 [PS-01~04](prepared-scene.md)의 사전 준비·원본 공간 통합으로 대체했습니다. 실행 관계 분석기와 원본 기록 계약은 유지합니다.

2026-11-12. 실행 관계 확장 E-01·E-03·E-07~E-09, R-01~R-07을 적용한 추가 표현입니다. 중간언어 생성과 자료구조 추론 규칙을 변경하지 않습니다.

## 입력 연결 — 구현

`scripts/animation/compiler-facts.mjs`는 이번 컴파일에서 얻은 AST와 plan의 LLVM/소스 노드 대응을 받습니다. 소스를 다시 분석하거나 컴파일하지 않습니다. 세션은 준비된 AST 노드를 반복 탐색 목록과 공유하며, 일괄 예제는 반환된 AST 덤프를 한 번 읽어 공유합니다.

- 표현식 소유 명령을 연결합니다.
- 단순 for/while은 실제 컴파일 분기의 선택 간선으로 반복 진입/종료를 연결합니다. do-while 및 분기 대응이 부족한 경우에는 입증 가능한 본문 첫 명령만 사용하며 부족한 경우 coverage에 남깁니다.
- 초기 지원 경계는 선언형 for의 단순 정수 증감·비교·1차원 직접 첨자입니다. 인덱스의 본문 변경·명시적 축소 변환·불명확한 호출 등은 경계를 추측하지 않습니다. 경계가 없더라도 실제 관측 접근은 표시합니다.
- 자료구조 추론의 `storageBindings` 및 기존 시점 대응을 연결합니다. 추론기가 만든 결과를 소비하며 구조를 새로 추론하지 않습니다.

세션/예제 응답의 별도 `workAnalysis`에 컴파일 근거·구조 대응·v2 실행 관계를 담습니다. 원본 plan/trace에는 추가하지 않습니다. 기록 후 별도 서버 Worker에서 최대 8초 동안 분석하며, 실패/시간 제한이면 확보한 원본을 반환합니다. 분석 실패/부분 결과가 원본 재생을 차단하거나 C ERROR가 되지 않습니다. 기존 입력 세션의 실행·입력 요청·사건 ID를 유지합니다.

## 표현 — 구현

원본 무한 공간과 스택·힙·전역/정적·함수 돗자리·상자·포인터는 유지합니다. 아래의 연결 보기는 같은 저장소를 가리키며 새로운 할당/복사가 아닙니다.

- 현재 코드·호출·명령, 도착한 피연산자와 계산 결과를 같은 패널에 표시합니다. 원본 ALU와 같은 시간선을 사용합니다.
- 관련 배열/멤버와 인덱스/포인터 슬롯을 현재 값으로 표시합니다. 실제 READ/WRITE와 주소 역할을 구별하며, 호출의 관측 누적 구간과 입증된 접근 가능 경계를 구분합니다. 가능한 범위를 방문 완료로 표시하지 않습니다.
- 재귀·일반 호출 진입으로 현재 함수의 접근 누적이 비어도, 살아 있는 호출자가 호출 직전까지 관측한 원본 저장소와 현재 기록된 포인터의 대상을 유지합니다. 현재 접근·고정 저장소를 우선하며 보조 저장소는 최대 6개입니다. 참조만으로 방문 범위를 만들지 않습니다. 호출자 조회의 과거 값은 사용하지 않고 같은 시점의 원본 장면에서 값을 가져옵니다. 소속과 객체 ID는 원본 그대로이며 새 배열/복사가 아닙니다.
- 작은 2차원 배열은 컴파일러 원소 경로대로 격자로 표시합니다. 큰 저장소는 현재 접근 주변 최대 24칸을 표시하고 생략을 명시합니다. 사용자가 여러 저장소를 고정할 수 있습니다.
- 시점이 확인된 구조 요소 대응이 있고, 요소 사이 실제 포인터 참조가 있으면 연결 요소 보기를 제공합니다. 현재 참조만 연결하고 순환·공유를 지우지 않습니다. 최대 12개 요소이며 생략을 표시합니다. 원본 멤버 보기와 원본 위치 이동을 제공합니다. 임의의 추론 구조 전체를 위한 완성된 렌더러는 아닙니다.
- 원본 실행 공간의 값 전달 화살표는 유지합니다. 보조 보기에는 데이터와 겹치지 않는 별도 줄에 출발지→도착지를 표시하며, 같은 전달 순서·강조·이동·함께 사라지는 시간을 사용합니다. 다른 상자의 이름/숫자 위로 SVG를 덮어 그리지 않습니다.
- 보조 상자는 내용 폭을 유지하며 가로 스크롤합니다. 값/멤버명이 이웃 칸으로 넘치거나, 짧은 칸이 긴 칸의 높이로 늘어나지 않습니다. 긴 표시의 원문은 칸의 title 또는 원본 멤버 보기에서 확인합니다. 접근 범위·구조 후보 등의 부가 메타데이터는 ⋯ 상세에 둡니다.
- WRITE의 숫자 표시는 실제 기록의 저장값과 값 도착 시점을 따릅니다. 이전 CALC의 피연산자나 인덱스 계산 결과를 현재 저장값인 것처럼 반복 표시하지 않습니다.
- 원본 위치 이동·고정·멤버 펼침·스크롤은 재생을 멈추지 않습니다. 수명 종료는 종료 상태로 표시하고 원본 위치 이동으로 되살리지 않습니다.
- 분석 안내는 준비/현재 위치 조회 중, 조회 실패·시간 제한, 분석 범위/예산 부족, 출처 연결 누락을 구별합니다. 접힌 요약을 펼치면 실제 근거 사건·소스 위치·한국어 사유·원문 진단 식별자가 나옵니다. 현재 명령 직전 경계의 진단이면 그 직전 사건을 명시합니다. 분석 안내가 데이터 표시를 대체하거나 C ERROR를 생성하지 않습니다. 실제 출처 링크의 미연결은 화면에서 복구된 것으로 보고하지 않습니다.
- 배열 없이 스칼라만 관련된 작업은 본문에 해당 상자를 표시합니다. 실제 저장소가 없는 단계는 함수 진입/매개변수 전달 대기 또는 접근 없음으로 설명하며 분석 실패와 구별합니다.

자동 강조는 실제 현재 피연산자·저장 대상·주소 관련 범위에 한정합니다. 상자/선을 직접 선택하거나 호버했을 때의 전체 포인터 연결 성분 탐색은 유지합니다. 과거의 모든 생산자를 현재 입력으로 함께 강조하지 않습니다.

## 시점과 비용

연결 보기의 값은 기존 before/after 장면에서 가져오며 WRITE의 값 도착 이전에 새 값을 노출하지 않습니다. v2 조회는 별도 브라우저 Worker에서 실행 기록당 한 번 구성하며 준비 제한은 10초입니다. 명령 경계당 before/after를 조회하고, 사건 내부 프레임마다 분석기를 재실행하지 않습니다. 슬라이더를 빠르게 움직이면 진행 중인 조회 하나 이후 최신 위치만 요청합니다. 구조 대응은 시점 변경 로그를 색인하며 뒤로 이동하면 prefix를 다시 적용합니다.

호출자 저장소의 표시 어댑터는 프레임별 사건 위치를 한 번 색인합니다. 현재 호출 스택에서 가까운 호출자 최대 32개의 해당 시점 이전 마지막 사건을 이진 탐색하고, 정지된 호출자의 조회 결과는 최대 64개 캐시에 재사용합니다. 생략한 호출자 수를 표시합니다. 이 어댑터는 공개 조회 결과를 소비하며 중간언어·분석기·조회 API의 의미를 변경하지 않습니다.

브라우저/Node가 같은 스냅샷 계약을 확인하도록 SHA-256을 공통 구현으로 사용합니다. 기존 지문 형식은 유지하며 Node crypto와 비교 검증합니다.

상단 ‘보기’에서 실행 공간·작업 보기·코드/중간언어를 각각 선택합니다. 최초 기본값은 실행 공간과 코드만 켜고 작업 보기는 끕니다. 선택과 작업 보기 너비는 브라우저에 저장합니다. 모두 끄면 보기 선택 안내를 표시합니다.

데스크톱에서 실행 공간과 작업 보기를 함께 켜면 좌우로 배치하고, 코드는 선택한 경우 맨 오른쪽에 둡니다. 세로 분할선을 드래그하거나 좌우 방향키로 너비를 조절하며 Home으로 기본 너비를 복원합니다. 한 보기만 선택하면 남은 너비를 사용합니다. 좁은 창은 가로/문서 스크롤을 허용합니다.

보기 전환은 재생·시점·원본 객체·선택한 확대율을 초기화하지 않습니다. 작업 보기의 ‘원본’ 이동은 실행 공간을 다시 켜고 해당 위치를 보여줍니다. 숨겨진 Canvas의 0 크기를 카메라에 반영하지 않습니다. 현재 명령이 바뀌거나 보기 너비가 바뀔 때 현재 접근 칸을 내부 가로 스크롤 범위 안으로 가져오며, 같은 사건 중의 수동 스크롤은 유지합니다.

카메라 조작부·도움말·진행 상태는 Canvas 밖의 독립 행에 둡니다. 기본 안내문/버튼이 실제 데이터와 화살표를 가리지 않습니다. ‘현재 작업’은 큰 배열 전체가 아닌 실제 접근 원소/접힌 대표 컨테이너를 대상으로 이동합니다. 원본 파일명은 짧게 표시하고 전체 경로는 title에 보존합니다.

## 남은 범위

일반 while/do의 정확한 미래 경계, 다차원/비아핀 도메인 증명, 모든 추론 결과의 전용 도형, 큰 구조의 최적 부분 선택/페이지 탐색, 노드 배치의 자동 최적화는 이번 구현의 완료 범위가 아닙니다. 기본 저장소·관측 범위·원본 재생은 계속 제공합니다. 2026-11-13에 추천 표현·기본 수동 표현 선택과 [자료구조 기본 도형](structure-visualization.md)을 연결했습니다. 같은 표현의 여러 역할 해석을 직접 편집하는 UI는 남아 있습니다.
