# 현재 연산을 따라가는 도구 배치

2026-11-12. 사용자가 알루를 유지하고 연산 도구가 움직이도록 요청한 범위입니다. 애니메이션 기본 원칙과 실행 관계 R-02~R-05, 기존 수동 배치 우선 규칙을 적용합니다.

- T-01 현재 CALC 또는 직접 수행하는 조건 판정의 기록된 입력 원소·멤버·반환구를 배치 근거로 사용합니다. 알려진 대상이 없으면 현재 살아 있는 호출 프레임을 사용하고, 그것도 없으면 기존 자리를 유지합니다. 상수의 가상 출발 상자나 미래 WRITE 주소를 만들지 않습니다.
- T-02 도구 작업대는 데이터 필드 옆의 후보를 비교해 이동합니다. 입력까지의 거리·이동량을 함께 줄이며 작은 이득만 있을 때는 자리를 유지합니다. 고정 작업대까지 데이터를 보내는 구조에서 현재 데이터 근처로 도구가 오는 구조로 바꿉니다. 알고리즘·자료구조 추론을 호출하지 않습니다.
- T-03 같은 계산과 그 결과 저장·완료 분기는 위치를 공유합니다. 사건 내부 매 프레임마다 다시 배치하지 않습니다. 위치 변경은 준비 경계의 화면 상태이며 IR 명령·실행 순서·값·수명·시간선·재생 상태를 변경하지 않습니다. 원본 사건의 값 전달선은 새 도구 위치에 연결됩니다.
- T-03 보완: PS-06의 표시 이력에서 도구 위치도 같은 원본 사건 순서로 준비합니다. 건너뛰기/되감기의 도착 지점만 보고 배치기를 새로 시작하지 않습니다. 사용자가 고정한 도구 좌표는 보기 설정으로 유지합니다.
- T-04 입력·출력·함수·힙·전역 필드와 겹치지 않게 배치하고, 자동 도구가 다른 필드에 공간을 양보합니다. 작업대를 직접 드래그하면 수동 고정하며 배치 초기화로 자동 이동을 복원합니다. 도구의 자동 배치 때문에 사용자 카메라를 강제 이동하거나 자동 정지하지 않습니다.
- T-05 상위 도구/데이터를 동시에 모두 읽을 수 있게 하는 추가 보기·자료구조 배치, 캐릭터 운반 및 도구의 연속 이동 경로 연출은 이번 구현의 완료 범위가 아닙니다. 현재는 명령 경계에서 작업대 위치가 바뀌고 기존 도구 등장 연출을 사용합니다. 관련 경로와 실제 화면을 별도로 검증합니다.
