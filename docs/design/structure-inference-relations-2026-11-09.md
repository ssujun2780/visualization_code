# 저장 관계에서 자료구조 후보로 연결 — 2026-11-09

[후속 감사 수정](structure-followup-fixes-2026-11-09.md)의 관측 관계를 실제 구조 후보와 추천에 연결한 추가 변경입니다. 공통 추론 모델만 수정했습니다. 원본 C의 변수 이름·예제 번호·예상 출력으로 분류하지 않으며, READ·WRITE·CALC·FLOW·SPACE의 값이나 실행 순서·객체 수명을 바꾸지 않습니다.

## 공통 규칙

### 여러 배열에 나뉜 논리 노드

`coindexed-record-candidate`는 같은 **실행상 인덱스 출처**를 사용하는 배열들을 묶습니다. 같은 길이·숫자만으로 묶지 않습니다. 인덱스 계산 결과가 우연히 같아진 경우, 초기화 WRITE만 있는 경우, 같은 저장소를 다른 타입으로 본 별칭은 별도 필드로 만들지 않습니다.

- `arrays`: 원본 배열 ID·범위·원소 폭·용량. 배열 길이가 달라도 가능합니다.
- `logicalNodes[].parts`: 같은 인덱스에 대응하는 각 배열의 실제 바이트 범위. 새 메모리를 할당하거나 기존 상자를 복제하지 않습니다.
- `evidence`: 실제로 함께 사용된 인덱스와 접근 사건.
- `relationEvidence`: 배열 원소에서 읽은 정수가 실제 다른 원소의 인덱스로 전달된 경로.
- `terminationEvidence`: 저장된 종료값을 검사하고 접근 전에 반환·탈출한 경로.
- `changes`: 필드 관찰·연결 변경·객체 종료 기록. 관측된 슬롯만 추적하며 전체 용량을 무조건 펼치지 않습니다.

A/B가 함께 쓰이고 다른 곳에서 B/C가 함께 쓰였다고 A/B/C를 자동 합치지 않습니다. 겹치는 묶음은 대안으로 유지합니다. 단순 병렬 배열 사용만 있으면 묶인 배열 후보이며, 값이 실제 인덱스로 전달된 경우에만 연결선을 만듭니다.

연결 필드에 다시 쓰면 이전 선은 미확정 상태로 바뀝니다. 예전 값을 임시 변수로 운반해 나중에 사용해도 현재 필드의 선으로 되살리지 않습니다. 원본 또는 대상 저장소가 종료되면 그 상태를 남깁니다.

### 종료값과 함수 인자 검사

`if (a[k] < 0) return k;`처럼 저장값을 직접 검사하는 경우와, `walk(a[k])`에서 받은 인자를 검사하여 접근 전에 반환하는 경우를 연결합니다. 비교 방향 반전, 반복 종료, 재귀 호출도 동일한 값 출처·AST·실제 FLOW 근거를 사용합니다.

함수 인자 검사는 그 함수의 정상 호출에서 **같은 AST 피연산자가 같은 배열을 인덱싱한 근거**도 필요합니다. 단순히 음수에 반응하는 별도 계산 함수를 호출했다고 연결 종료로 해석하지 않습니다. 복합 조건의 일부 비교만으로 전체 탈출 원인을 단정하지 않습니다.

숫자 자체는 그대로 보존합니다. 예를 들어 `-4`는 `-4`로 남으며, 관측된 종료 규약에 해당할 때만 표현상의 종료 표지가 됩니다. 이를 DSU의 크기나 특정 알고리즘 의미로 확정하지 않습니다. 후속 공통 보완에서는 `0` 같은 범위 안의 값도 실제 방문을 막은 분기 근거가 있을 때 해당 관계의 종료로 기록합니다. 숫자만으로 센티널을 지정하거나 미방문 슬롯으로 이 판정을 확장하지 않습니다.

직접 확인한 종료와 같은 규약에서 추론한 다른 슬롯을 구별합니다. 종료 근거 이전으로 이동하면 표지는 없으며, 이후 WRITE는 해당 슬롯의 직접 확인 근거를 무효화합니다. 자료구조 후보의 범위 밖 상태는 실제 C 런타임 ERROR를 생성하지 않습니다.

### 시간별 조회·추천

공개 API `queryCoindexedRecords(structure, trace, {afterExecutionId})`로 해당 시점의 원본 필드·연결·종료 상태를 조회합니다. `recommendStructureViews`는 이 후보도 처리합니다.

관측된 방문 영역에서 각 연결 역할이 실제 연결 또는 확인된 종료로 설명될 때 토폴로지를 평가합니다. 용량만 예약한 슬롯을 논리 노드로 채우지 않으며, 포함·제외 인덱스와 판정 범위를 남깁니다. 그 범위에서 순환과 공유 자식이 없으면 트리·포레스트, 자식 수 조건이 맞으면 이진 트리 등을 추천합니다. 방문한 노드의 미관측 역할이나 불완전한 연결은 부분 그래프로 남깁니다. 이후 공유 자식이나 순환이 생기면 트리 추천을 해제합니다.

이는 **관측된 역할·저장 범위의 완전성**이며 작성자의 의도나 모든 입력에서의 불변식 증명이 아닙니다. 추천 상위 다섯 종류와 사용자 지정 우선 규칙은 유지합니다. UI·애니메이션은 변경하지 않았습니다.

## 남은 범위

트리 관계의 삼항식 종료, 여러 인덱스 역할 결합, 포인터 논리 보기, 힙 비교 별칭, 읽기 중심 범위 보완은 [트리 관계의 논리적 보기](tree-inference-projections.md)에 정리했습니다. BST 등 세부 종류의 의미 판별과는 구별합니다.

후속 [공통 보완](structure-common-fixes-2026-11-09.md)에서 관측된 인덱스 전달과 같은 비교 피연산자의 정점 접근을 조합하는 `index-domain-graph-candidate`를 추가했습니다. CSR의 구간 출처, 간선 레코드, 연결 리스트의 루트, 함께 인덱싱한 속성은 그 근거로 연결합니다. CSR·최단경로라는 알고리즘 의미, 비트셋의 비트→정점 의미, Fenwick·해시 등의 의미는 자동 확정하지 않습니다. 실제로 방문하지 않은 슬롯이나 구분되지 않는 역할은 추정값으로 채우지 않습니다.
