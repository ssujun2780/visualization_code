# 값 전달 화살표: 전체 경로와 순차 강조

상위 문서는 [애니메이션](animation.md)·[시각화](visualization.md)·[UI](ui.md)입니다. 이 문서는 값 전달 경로와 미리보기·순차 강조의 세부 명세입니다.

2026-11-09 작성. 2026-11-10부터 개별 전달 사건의 시간을 확보하는 [명령어 시간선](animation-incidents.md)을 사용한다. 중간언어 명령어 및 그 순서는 유지한다.

## 표시 상태

- 중간언어 행·진행 막대·이전 버튼으로 이동하면 `inspect` 상태다. 해당 명령어의 모든 전달 경로와 순번을 함께 표시한다. 알루가 필요한 명령어는 알루도 바로 표시한다. 미리보기만으로 변수값을 쓰거나 명령어를 실행하지 않는다.
- 재생·한 명령어·한 줄은 `playback` 상태로 전환한다. 전체 경로를 유지하고 기록된 입력 순서대로 하나씩 강조한다. 현재 값의 이동은 해당 경로의 점과 숫자로 표시한다. 도착한 피연산자는 알루에 남는다.
- 마지막 전달 후 전체 경로가 함께 흐려져 사라진다. 일시정지는 이 상태를 그대로 고정한다. 다음 명령어에서는 다음 명령어의 전달 경로를 사용한다.
- 계산 명령어의 입력 경로를 다음 WRITE에서 다시 재생하지 않는다. 예: CALC의 a→알루, b→알루와 WRITE의 알루→c는 각 명령어에 속한다. 상수에 가짜 출발 상자를 만들지 않는다.
- inspection 여부는 `playing === false`와 구분한다. 재생 중 정지는 순차 강조 위치를 보존하고, 행 선택은 전체 경로 미리보기로 돌아간다.

## 색과 기하

기본선은 주황색 `#ed9b43`, 강조선은 밝은 `#ffe0a0`이다. 강조선은 더 굵고 선명하다. 전역 포인터 배선과 독립적인 레이어다. 돗자리와 컨테이너의 빈 공간은 통과할 수 있지만, 값 상자의 내용·자료형·영역 제목은 가리지 않는다.

`transfer-routing.js`는 한 명령어의 경로 전체를 함께 배치한다. 출발·도착 연결점을 분산하여 직선을 우선하고, 선이나 표시 내용을 침범하면 다른 연결점 또는 직선 구간으로 된 우회로를 선택한다. 우회로는 연결면에서 바깥으로 나가는 짧은 구간을 확보하여 상자 테두리를 따라 붙어 흐르지 않게 한다. 필요하면 기존 전달선과 보호할 내용 영역을 장애물로 삼는 가시성 탐색을 사용한다. 같은 상자에서 같은 값을 여러 번 읽어도 전달 순번과 경로를 합치지 않는다.

여유가 있으면 확대율을 반영하여 화면상 16px 간격을 확보하고, 밀집한 경우 8px, 마지막으로 월드 4 단위 간격까지 사용한다. 확대율이 바뀌면 경로를 갱신한다. 실제 최소 선간 거리에 맞추어 선 굵기·화살촉·이동 점 크기를 제한한다. 배치할 수 없는 선은 교차하거나 내용을 덮는 임시선으로 대체하지 않고 화면에 배치 미완료 개수를 표시한다.

출발점은 작은 점으로 표시하고 번호는 출발 상자에 가까운 빈 곳부터 배치한다. 번호는 화면상 반지름 8px로 값 상자나 다른 경로를 가리지 않으며, 강조가 달라져도 위치가 바뀌지 않는다. 번호를 놓을 공간이 없는 짧거나 밀집한 경로는 번호를 생략할 수 있으며, 현재 전달 순번은 작업 상태에도 표시한다.

## 구현 경계

생략된 주소 인자는 [공통 주소 출처 계약](address-origin-contract.md)을 소비합니다. 실제 관측 주소를 같은 전달 시간선에 싣고, 원본 객체 주소와 포인터 기저를 구별합니다. 주소 화살표로 배열 내용 READ를 만들지 않으며 숨긴 보조 저장소 규칙은 유지합니다.

- `transfers.js`: 전체 edge 목록, 현재 강조, 도착 여부, 결과 준비 여부, 전체 투명도를 계산한다. 도착·쓰기·결과 확인을 사건별 시간선의 서로 다른 시점으로 나눈다.
- `playback.js`: `inspect` / `playback` 표시 모드를 관리한다. 기록의 명령어가나 상태 전이는 추가하지 않는다.
- `tools.js`: 미리보기와 실제 경로가 존재하는 동안 대상 도구가 보이도록 한다.
- `canvas.js`: 전체 경로를 기본색으로 그리고 현재 전달만 강조색으로 그린다. 명령어·기하별 배치 캐시를 사용하므로 강조 프레임마다 경로를 다시 정하지 않는다.
- `main.js`: 행 선택과 재생 조작을 연결하고 현재 미리보기·전달 순번을 표시한다.

## 확인

관련 테스트 52개로 검사한다. 실제 C 코드를 현재 모델로 실행하여 산술·반복 피연산자·논리·비트 연산, 인자 전달, 반환, 복사와 출력을 동일한 렌더러로 검사한다. 검사 전후 기록의 내용·순서와 변수 상태가 변하지 않는지도 확인한다.

합성 기하 검사는 다중 입력, 같은 상자의 반복 읽기 2/8/16개, 교차 배치, 음수 좌표 및 여러 방향의 연결을 검사한다. 값 상자가 일렬로 놓인 수평·수직 배치에 확대율 0.34/0.68/1.25를 적용하여 내용 침범·출발면 이탈·16px 선 간격도 확인한다. 실제 C 실행의 모든 전달에서 보이는 상자 내용을 침범하지 않는지도 검사한다. 전체 경로 유지, 단일 강조, 공통 소멸, 정지·재개, 배치 이동 후 갱신과 순번 표시를 확인하며 전체 C 예제 모음은 다시 실행하지 않는다.
