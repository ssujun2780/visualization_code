# 그래프 관계와 작업 저장소의 관측 계약

2026-11-11. 선택적 추론기의 구현 범위입니다. 중간언어 생성·실행·UI는 변경하지 않습니다.

1. **근거 식별:** 한 CALC가 여러 끝점 관계를 뒷받침할 수 있습니다. 사건 ID와 관계 근거 ID를 구별하며, 저장 역할 재사용은 원래 읽기·끝점·속성 역할을 포함하는 정확히 하나의 근거에 연결합니다.
2. **인접 관계 발견:** 행렬 셀의 실행된 조건 검사와 같은 열 커서를 사용한 목적지 접근을 연결합니다. 개수 기반 인접 행은 같은 행의 개수 읽기, 현재 열의 반복 조건, 셀 값이 실제 목적지 인덱스로 전달된 기록을 함께 요구합니다. 예약 열과 미실행 행을 간선으로 보충하지 않습니다. 큐 삽입 성공 여부와 간선 존재는 별개입니다.
3. **역할 분리:** 원래 연결과 그 연결을 거쳐 갱신한 보조 상태를 별도 후보로 보존합니다. 동일한 원본 읽기·인덱스 전달 근거가 확인된 보조 상태의 모양을 전체 그래프보다 우선하지 않습니다. 숫자 1을 방문 완료로 해석하지 않습니다.
4. **개수 기반 원형 큐:** 실제 두 커서와 개수 슬롯, 용량에 따른 모듈러 갱신, 개수 증감, 소비를 제어한 조건을 요구합니다. 슬롯 번호와 해당 삽입 WRITE의 출처를 함께 대조해 FIFO를 검사합니다. 같은 값은 같은 원소의 증거가 아닙니다. 조건이 호출자에 있으면 실제 호출/반환 식별자로 연결합니다. 필요한 근거가 관측되기 전에는 추천하지 않습니다. 현재 어댑터는 관측 구간 전체에서 이 조건이 일치하는 경우를 지원합니다.
5. **통째 복사와 인덱스 관계:** COPY 목적지에 소스 AST가 없으면 보조 관찰의 실제 GEP·인덱스 READ·원소 범위를 연결합니다. 소스 문자열을 재해석하거나 중간언어 사건을 추가하지 않습니다. 현재 보조 경로는 선언 배열의 `[0,index]` GEP와 비트 캐스트를 지원하며, 다른 주소 형태의 지원을 주장하지 않습니다. 내부 주소에서 시작하는 배열 보기에 원래 배열의 좌표 공식을 그대로 적용하지 않습니다.
6. **구조체 순서 조건:** 비교된 필드의 바이트 오프셋·크기·자료형을 추론하고 레코드 전체 이동과 구별합니다. 점유 접두 구간 안에서 최소/최대 순서 조건을 검사하며, 연산 도중 위반 상태도 보존합니다. 실제로 완료된 연속 삽입 `0→1→2…`는 점유 범위의 추가 근거입니다. 이 관계와 필드 비교, 비자명한 순서 조건이 관측된 경우 heap 보기를 부분 후보로 추천할 수 있지만 알고리즘 의도나 이후 불변식을 증명한 것은 아닙니다.
7. **비교문 없는 선형 FIFO:** 두 독립 커서의 동일 시작 위치·같은 인덱스 오프셋·실제 증가와 삽입/소비를 확인합니다. 소비 READ가 가장 먼저 대기 중인 삽입 WRITE에서 왔는지 저장 위치와 사건 식별자로 대조합니다. 비교문이 없으면 이 근거가 처음 완료된 시점부터 후보를 제공합니다. 값이 같은 다른 삽입, 덮어쓴 슬롯, 단순 배열 복사는 FIFO 근거를 대신하지 않습니다. 관측 후 불일치도 상태에 남깁니다.
8. **분리 배열의 연결 인접 목록:** 시작 배열의 원소에서 읽은 간선 번호, 같은 커서로 읽고 그 커서에 돌려쓰는 다음 연결, 그 간선 번호로 읽은 목적지가 실제 정점 저장소 인덱스로 전달된 기록을 합성합니다. 같은 반복 분기의 동적 커서 버전과 READ→WRITE 계보를 요구합니다. 다음 연결을 처음 확인하기 전으로 추론 시점을 앞당기지 않으며, 간선의 원본 시작/연결/목적지 슬롯이 바뀌면 기존 관계를 미확인 상태로 남깁니다. 병렬 간선·자기 연결을 합쳐 없애지 않습니다. 현재 어댑터는 직접 정수 인덱스의 분리 배열을 다루며, 산술 변환이나 미방문 간선·고립 정점을 추측해서 보충하지 않습니다.

추천 상위 5개·사용자 지정 우선 규칙은 그대로 적용합니다. 크루스칼 입력 간선, 선택한 간선 부분집합, DSU 부모 관계의 자동 합성과 탐색 완료 색칠은 별도 미구현 항목입니다.
