# 자료구조별 모양과 원본 공간

2026-11-13 사용자 승인 구현. PS-02·03, SV-01~03, R-01~07의 원본 정체성·수명·현재 값·사건 순서를 유지합니다. 추론기와 중간언어 생성 코드는 수정하지 않습니다.

## SS-01 공통 입력

종류·구성원·바이트 범위·실제 관계·역할은 기존 조회 결과에서 받습니다. 원소 값과 간선 가중치의 저장 범위는 현재 재생 메모리에서 읽습니다. 색·높이는 기존 조건 조회가 확인한 속성이 있을 때 표시합니다. 조회/준비 어댑터는 variant, 방향, 구간, 버킷, 대표, 부모, 종료 표지 등을 보존합니다. 지연 인덱스 힙은 `queryIndexRelations`로 관측된 활성 구간만 펼칩니다. 용량 전체를 구성원으로 간주하지 않습니다.

공유 추론 저장 형식은 조회와 이력 준비 양쪽에서 먼저 복원합니다. 후보 목록만 복원한 채 원본 인코딩에서 상태 이력을 찾지 않습니다. 후보의 `layout: ring/flag-ring`은 표현 설명으로 인계합니다. 일반 `logicalOrder.modulus`는 좌표 정규화 정보일 수 있으므로 원형 배치의 근거가 아닙니다. 명시적 원형 variant/layout 또는 이미 큐/덱으로 판정된 관계의 관측된 순환 주소 정보만 원형 모양에 사용합니다.

공개 추천이 선택한 후보에 현재 `nodes/edges` 상태 스냅샷이 있지만 공통 관계 조회에 아직 투영기가 없으면, 화면 어댑터는 그 제공된 사실을 소비합니다. 후보 종류를 재판정하거나 연결을 계산하지 않습니다. 발견 전·이력 생략·수명 종료·WRITE 뒤 미확정 연결은 현재 간선으로 대체하지 않습니다. 여러 배열이 같은 그래프를 구현하면 정점 저장소에 그래프를 한 번 표시하고, 인접/보조 저장소는 원본 배열을 계속 보여 줍니다. 이 역할은 전체 준비 자료로 고정합니다.

## SS-02 기본 모양

| 종류 | 구현한 표현 |
| --- | --- |
| 배열·동적 배열·문자 배열 | 원본 인덱스 칸, 확인된 사용/비사용 구간과 실제 문자/종결 값 |
| 다차원 배열 | 행·열 격자. 3차원 이상은 평면 나열 |
| 스택 | 고정 칸의 세로 배치, 제공된 top 표지 |
| 큐·덱 | 가로 슬롯, 제공된 front/rear 표지 |
| 원형 큐·원형 리스트 | 원 둘레의 슬롯/노드. 물리 슬롯 고정, 커서와 현재 값만 변경. 안내 고리는 포인터 선이 아님 |
| 연결 리스트 | 실제 연결 순서. 역방향·순환·자기 연결도 삭제하지 않음 |
| 트리·BST·AVL·Red-black·힙·트라이·포레스트 | 층별 원형 노드와 실제 간선. 제공된 색·높이·문자 간선·종료 표지. 루트별 트리와 미연결 노드 보존 |
| 그래프·DAG | 원형 정점과 직선/곡선 간선, 방향·가중치, 평행 간선·자기 연결. DAG는 층 배치 |
| 해시 | 확인된 버킷별 줄과 키/값 필드, 실제 충돌 연결 |
| Union-Find | 실제 부모를 가리키는 트리들의 집합, 대표 표지와 현재 부모 저장값 |
| 구간 트리·Fenwick·구간 집계 | 공급된 관계의 노드와 담당 구간, 실제 저장값 |
| 여러 키가 있는 트리 | 전달받은 노드 범위 안의 필드를 가로 분할하는 기본 그리기 경로. 키 역할이 없으면 미확정 표지. 모든 B트리 계열의 자동 추론/전용 동작을 뜻하지 않음 |

서로소 집합의 부모가 별도 간선이 아닌 관측 경로로 전달되면 그 경로의 다음 원소를 부모 관계로 소비합니다. 대표가 같다는 이유로 모든 원소를 대표에 직접 연결하지 않습니다. 경로 압축·병합·회전은 실제 사건이 바꾼 연결과 값으로 표시합니다. 전용 회전 동작이나 노드 이동 보간을 새 명령으로 만들지 않습니다.

## SS-03 표시와 조작

원래 함수·전역·힙 공간 안의 같은 객체/셀을 그립니다. 원형 셀도 실제 포트 ID와 바이트 범위를 유지합니다. 구조체 일부만 큐 저장소이면 그 밖의 관리 필드는 같은 원본 상자에 별도로 남깁니다. 인덱스만 있는 논리 정점은 그림 요소이며 가상 C 객체/주소/값을 생성하지 않습니다.

가중치 표시는 원래 저장 범위를 갖는 표현 연결점입니다. 그 값을 읽는 전달선과 알루 배치는 같은 범위의 그래프 숫자 위치를 사용할 수 있습니다. 원본 객체/셀과 소속은 유지하며 복사나 READ 명령을 추가하지 않습니다. 공유 역할 범위는 현재 메모리의 표시 창에 포함하여 이미 초기화된 가중치를 방문 전에도 읽을 수 있게 합니다. 초기화되지 않은 가중치는 `?`이며 최종 값을 가져오지 않습니다.

구조 간선은 상자 배경 뒤에 가려지지 않는 레이어에서 그립니다. 해당 역할의 실제 포인터 연결 ID가 있는 경우 같은 선을 두 번 그리지 않습니다. 선·정점 선택과 현재 접근 범위에 따라 강조하며, 바깥 컨테이너 선택을 내부의 모든 포인터 선택으로 바꾸지 않습니다. 값 전달의 주황색 시간선은 별도로 유지합니다.

트리 계열의 부모·자식 관계선은 평상시에도 선명한 민트색 실선·채운 화살촉과 어두운 외곽선으로 표시하며, 다른 지속 선 위에 그립니다. 기본 선은 화면상 2.6px, 강조 시 3.6px이고 축소에 맞춰 보정합니다. 이 규칙은 다른 일반 포인터선·값 전달선의 굵기나 색을 변경하지 않습니다.

선택한 저장소의 표현을 바꿀 수 있습니다. 그래프는 기록된 방향·방향 그래프·무방향 그래프를 선택합니다. 명시적 무방향 보기에서만 같은 가중치의 상호 간선을 짝지어 표시하고 원본 연결 ID들을 보존합니다. 방향을 대칭 저장이나 변수명으로 추측하지 않습니다.

## SS-04 준비와 검증 경계

준비된 장면을 `{plan, trace, preparedScene}`로 열 수 있습니다. 프로그램·실행 ID와 사건 수를 대조합니다. `scripts/animation/prepare-view-file.mjs`는 저장된 실행/추론을 소비하며 C와 추론기를 다시 실행하지 않습니다. 준비 정보는 표현 캐시이고 원본 실행 상태를 대체하지 않습니다.

미확정 역할은 미확정으로 남깁니다. 근거 없는 그래프 탐색 완료/확정 색, 정답 경로, 미실행 분기, 자동 AVL/RB 복구는 생성하지 않습니다. 2026-11-14부터 [ST-01~05](structure-transitions.md)의 시점별 국소 배치·속성 변화·위치 보간을 사용합니다. 구조 종류·물리 슬롯은 유지하며 중간 연결을 정상 트리로 고치지 않습니다. 자료구조의 추론 품질·속도와 시각화 검증을 구별합니다. [새 검증 대응표](../validation/structure-transitions.md), [기존 모양 검증](../validation/structure-shapes.md)을 참고합니다.

PS-02의 표현 고정은 원형·방향·물리 슬롯까지 포함합니다. 재생 시점의 논리 길이나 관계 존재 여부로 도형을 재선택하지 않습니다. 배치용 전체 노드 목록의 색·높이·담당 구간은 현재 속성이 아니므로 화면 값으로 사용하지 않습니다.
