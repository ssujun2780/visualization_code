# 트리 관계의 논리적 보기

추론기는 확정된 AST·실행 기록을 읽는 소비자입니다. 사건, 값, 수명, 실행 순서를 변경하지 않습니다. 변수명이나 예제 번호로 종류를 판별하지 않습니다. 모든 후보는 의도가 확정되지 않은 추천이며, 사용자 지정 표현이 우선합니다.

## 근거와 표현

| 구분 | 공통 처리 | 보존하는 정보 |
| --- | --- | --- |
| 삼항식 종료 | 실제 조건 평가와 선택된 반환을 연결하고, 같은 매개변수가 비종료 경로의 실제 인덱스로 사용된 근거를 확인합니다. | 음수라는 이유만으로 종료값을 만들지 않습니다. 다른 계산에 포함된 비교 결과를 전체 분기 결과로 취급하지 않습니다. |
| 여러 정수 연결 역할 | 같은 순회 함수에서 실제 사용한 역할들을 루트의 도달 가능 영역으로 함께 묶습니다. | 역할별 경로, 전체 저장 그래프, 순환·공유 자식·미관측 연결을 유지합니다. 배열을 나누어 저장한 경우 기존 공동 인덱스 관계가 있어야 같은 가족으로 다룹니다. |
| 개수로 관리하는 포인터 배열 | `[0,count)`의 실제 방문과 정상 루프 종료로 필드와 사용 범위를 연결합니다. 개수 쓰기가 발생하면 기존 범위 근거를 무효화합니다. | 용량 밖이 아니라 **사용 범위 밖**인 슬롯도 실제 저장소에는 남습니다. 읽지 않은 슬롯이나 중간에 종료된 순회로 전체 범위를 확정하지 않습니다. 0개 자식도 확인된 개수 필드와 종료 근거로 표현합니다. |
| 부모 포인터 | 관측된 단일 연결 역할의 각 연결 성분에서 모든 경로가 확인된 종료에 도달하는지 검사합니다. 분기하는 역방향 관계를 부모→자식 보기 후보로 제공합니다. | 저장 방향은 자식→부모 그대로입니다. 순환·미확인 연결이면 완전한 부모 트리로 확정하지 않습니다. 다른 순회 역할도 관측되면 이 단일 역할 해석을 해제합니다. |
| 첫 자식·다음 형제 | 같은 재귀 호출 지점에서 첫 인자가 부모의 필드에서 오고, 후속 인자가 직전 자식의 다른 필드에서 오는 실제 전달을 확인합니다. | `storedEdgeIds`에 부모→첫 자식→형제 경로를 남깁니다. 논리 간선이 실제 포인터 한 개처럼 보이지 않도록 별도 보기로 제공합니다. |
| 추천 범위 | 구성원 식별자의 합집합으로 가족 범위를 계산하고 각 추천의 실제 구성원 수를 기록합니다. 전체 범위를 보여주는 후보를 부분 경로보다 먼저 제시합니다. | 상위 5개 제한과 사용자 지정 우선 규칙은 그대로입니다. 수를 모르면 누락 수도 `null`이며 0으로 가정하지 않습니다. |
| 배열 별칭과 힙 비교 | 원본 객체·바이트 오프셋·접근 폭·원소 정렬로 현재 비교 슬롯을 정규화합니다. | 복사되어 다른 장소에 있는 값의 과거 출처는 현재 슬롯과 구별합니다. 비교 방향은 의도 후보이고, 실제 순서 조건은 시점별로 별도 검사합니다. |
| 읽기 중심 인덱스 트리 | 실제 `[0,bound)` 순회 완료를 사용 범위의 근거로 남깁니다. 같은 순회 지점의 새 관측은 이전 관측을 대체하고, 개수의 전달 원본이 바뀌면 기존 근거를 무효화합니다. | 조기 `break`, 단순 최대 접근 인덱스, 예약 용량만으로 길이를 확정하지 않습니다. 서로 다른 순회 범위가 충돌하면 미확정으로 남깁니다. 정렬 비교가 없으면 힙 의도를 주장하지 않습니다. |

## 출력 계약

- `rooted-index-structure.roleCombinationEvidence`: 여러 연결 역할을 묶은 실행 근거입니다. 같은 역할 조합을 입증한 함수들 중 가장 이른 완성 근거를 사용합니다. 나중에 관측된 역할은 별도 확장 후보에만 포함하고, 근거 이전 시점에 합쳐진 후보를 노출하지 않습니다.
- 분리 배열의 `coindexed-record-candidate.evidence`는 같은 인덱스 출처에서 관계를 처음 입증한 접근들과 `afterExecutionId`를 기록합니다. 반복 접근이나 미래의 추가 필드 때문에 초기 관계를 지연·확장하지 않습니다. 발견 이전 조회의 논리 구성원은 비어 있습니다.
- 공유 종료 객체의 관리 필드 조회와 커서의 데이터 방문은 실제 객체 ID·레코드 오프셋으로 구분합니다. 종료 객체도 물리 저장 그래프에는 남고, 원형 리스트의 실제 시작 원소나 반환되는 종료 객체의 데이터는 제거하지 않습니다.
- `pointer-tree-projection`: `counted-children`, `inverse-parent`, `first-child-next-sibling` 모드를 가진 부가 보기입니다. `sourceStructureId`는 변경하지 않은 원본 포인터 그래프를 가리킵니다.
- 각 상태에 구성원 `nodes`, 논리 `edges`, `topology`, `evidenceExecutionIds`, 현재 선택 범위 `scopeRanges`를 기록합니다. 개수·연결·수명이 바뀌면 새 상태를 만들고, 이전 완전한 상태를 현재 상태로 재사용하지 않습니다.
- 논리 간선의 `storedEdgeIds`를 원본 그래프와 독립적으로 검증합니다. 역방향 부모 간선 또는 연속 포인터 경로의 양 끝점이 실제 연결과 일치해야 합니다.
- 포인터 보기의 기본 한도는 상태 2,048개, 루트 바인딩 256개입니다. 생략이 발생하면 `coverage`와 `historyGap`을 남깁니다.
- `index-tree.prefixMembershipEvidence`: 읽기 순회로 확인한 범위와 개수의 복사·매개변수 전달 출처입니다. `activeRange`가 미확정이면 순서 검사는 여전히 `physical-capacity-candidate` 범위임을 구분합니다.
- 추천의 `coverage`에는 실제 표시 수·가족 수·생략 수가 있으며, 선택한 루트, 범위 포함 정도, 행동 근거 순으로 우선순위를 정합니다. 동률은 안정된 식별자로 정렬합니다.

초기 트리 보기 작업에서는 BST 조상 범위·Red-black 균형 등 세부 조건을 별도 범위로 두었습니다. 단순 트리 형태와 세부 자료구조 의도는 계속 구분하며, 후속 구현 범위는 아래 연결 문서를 따릅니다.

2026-11-11 후속 작업에서 [정수·복합 키 BST 판별](bst-inference.md)을 추가했습니다. 이어 [기본 관계와 조건 조합](structure-composition.md)으로 BST 검사 경로를 분리하고 AVL·Red-black 조건 검사를 연결했습니다. 색 역할의 자동 추론은 미구현이며, 명시적으로 연결한 속성과 현재 관측 관계에만 검사합니다.

검증과 남은 생성 모델 문제는 [검증 기록](../validation/tree-inference-fixes-2026-11-10.md)에 정리했습니다.
