# 자료구조 추론 공통 보완: 관계 범위·저장 위치·방문 경계

2026-11-09. 30분 감사에서 정리한 일곱 항목의 후속 수정입니다. READ·WRITE·CALC·FLOW·SPACE는 변경하지 않고, 추론과 추천 메타데이터를 보완했습니다.

## 추론 근거와 범위

- 이름·예제 번호·출력값으로 분류하지 않습니다. AST의 선언/필드/피연산자 식별자, 관측 저장 범위, 데이터 의존성과 실제 분기를 사용합니다. 원본 C 텍스트를 추가로 해석하지 않습니다.
- 역할 일부만 본 트리와 전체 관계 그래프는 서로 다른 해석입니다. 일부 역할 보기는 대안으로 남기며 사용자 지정은 계속 우선합니다. 독립된 포인터 필드들을 무조건 하나의 자료구조로 합치지 않습니다.
- 구조체 배열의 `length: null`은 그대로 유지합니다. 방문한 노드의 관계가 완성되더라도 배열 전체의 논리적 크기를 알아냈다는 뜻은 아닙니다. 분리 배열도 포함·제외 인덱스와 `completenessScope`를 제공합니다.
- 경계 근거의 시점은 종료 분기와 정상 방문 근거가 모두 확보된 이후입니다. 값이 같아도 중간 WRITE가 있으면 오래된 직접 증거를 재사용하지 않습니다. 범위 밖 종료 규약을 다른 슬롯에 적용한 기존 후보는 `inferred-*`로 구별합니다.
- 포인터 저장 객체와 배열 저장 객체를 분리합니다. 포인터 변경별로 연결 구간을 기록하며, 수명과 미확정 바이트를 유지합니다. 부분 쓰기를 정상적인 포인터 참조로 간주하지 않습니다.
- `index-domain-graph-candidate`는 관측된 정점 관계 후보입니다. `rangeInputs`, `rootBindings`, `properties`가 각각 구간 출처·루트/연결 출처·속성의 근거를 담습니다. 단순히 정수가 같거나 함께 초기화되었다고 간선을 만들지 않습니다. 복합 논리식 전체의 모든 READ를 서로 연결하지 않고 해당 비교 피연산자의 출처를 추적합니다.
- 그래프 간선 방향의 알고리즘상 의미와 속성의 ‘가중치’ 의미는 미확정으로 남깁니다. 미방문 간선·고립 정점·모든 CSR/비트셋 표현을 완전히 복원했다는 보장은 없습니다. 상한에 걸리면 누락 수와 부분 상태를 기록합니다.
- 컨테이너 반례를 정상 순서로 보정하지 않습니다. 잘못된 count·끝 위치 접근, 중간 상태, 이동/복사 과정은 그대로 남깁니다. 함수 내부의 여러 쓰기를 포함하는 기존 작업 범위도 유지합니다.
