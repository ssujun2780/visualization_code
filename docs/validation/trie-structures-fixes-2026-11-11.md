## 추가 변형과 반례

`tests/ir-sequence-lookups.test.js`는 소스와 예상 관계를 먼저 작성한 뒤 실행했습니다.

| 검사 | 결과 |
| --- | --- |
| 문자 0/1/2, 루트 bank[2], 3개 자식 슬롯, 인덱스 입력, flag=7, noise=99 | 통과. 노드 2/3/4/5, 2-0→3·2-2→5·3-1→4, 종료 3/4/5 |
| 삼중 논리식과 후위 증가를 쓰는 순환 형제 검색 | **생성 단계 오류로 차단**, 추론 통과로 처리하지 않음 |
| 포인터가 먼저인 Edge, 힙 문자열, 라벨 접두어 충돌, free | 통과. 처음에는 trie, 충돌/해제 후에는 확정하지 않음 |
| 종료 배열까지 있는 순환 자동자 | 통과. 입력 소비·종료 역할을 찾되 trie로 오인하지 않음 |
| 명시적 if/break 형식의 별도 순환 형제 검색 | 통과. 노드 0/1/2와 논리 자식 0→1·0→2, 물리 형제 순환 충돌 보존 |

따라서 새 테스트 파일은 **4통과·1실패**이며 전체 성공으로 보고하지 않습니다. 실패한 소스와 `completed` 기대 조건을 그대로 유지했습니다. 별도 if/break 예제는 기존 실패를 대체하지 않습니다.

범위 밖 실패 재현 코드:

```c
while(q && q->symbol != *s && steps++ < 3)
    q = q->side;
```

일반 컴파일 실행은 `A 1`로 정상 종료했습니다. 중간언어 생성은 `ir-recording` 단계에서 `CALC 계약 위반 (x37): 현재 식 q&&q->symbol!=*s에서 얻은 입력 x32가 누락됐습니다.`로 실패합니다. 원본 결과는 `test-results/trie-structures-fixes-2026-11-11/variant2.json`입니다. 중간언어 생성 모델 수정은 이번 요청에서 제외되어 보류했습니다.

공유 관계의 기존 검사 `ir-tree-inference.test.js`, `ir-structure-composition.test.js` **13/13 통과**. 전체 예제/전체 테스트를 재실행하지 않았습니다.
