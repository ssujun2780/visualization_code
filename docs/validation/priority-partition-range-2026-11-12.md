## 범위와 계약

힙·우선순위 큐, 분리 집합, 구간 자료구조를 소스 예상 → 실제 중간언어 생성 → 별도 추론 순서로 점검했습니다. 생성 모델과 UI는 변경하지 않았습니다.

읽은 계약: `presentation.md` 모델 경계, `inference-model.md` 경계/API, `structure-presentation-policy.md` 적용 규칙·공통 API, `structure-composition.md` RC-01~08, `graph-worklist-relations.md` 구조체 순서 조건과 미구현 범위. 추가 계약은 `priority-partition-range-inference.md` PPR-01~05입니다.

예제는 `example/c/codex_code/priority_partition_range_20261112/`, 최초 예상과 원본 실행·추론은 `test-results/priority-partition-range-2026-11-12/`에 보존합니다. 생산 코드에 파일명·변수명·테스트 정답에 따른 분기는 없습니다.

## 최초 예상의 오류와 수정

첫 힙 세 예제에서 예상 배열을 잘못 적었습니다. 최초 `expectations.json`은 덮어쓰지 않고 남겼습니다. `expectations-reviewed.json`과 독립 삽입 시뮬레이터가 정정 근거입니다. 힙의 내부 배열은 정렬 결과와 다릅니다.

- 이진 최대 힙 `[4,9,2,9]`: `[4] → [9,4] → [9,4,2] → [9,9,2,4]`. 최초 예상 `[9,9,4,2]`가 잘못되었습니다.
- 1번 기반 이진 최소 힙: `[4] → [4,9] → [2,9,4] → [2,9,4,9]`. 최초 예상 `[2,4,9,9]`가 잘못되었습니다.
- 3진 최소 힙 `[4,9,2,4,-1]`: `[4] → [4,9] → [2,9,4] → [2,9,4,4] → [-1,2,4,4,9]`. 최초 예상 `[-1,4,2,9,4]`가 잘못되었습니다.

출력에 맞추기 위해 순서 검사를 삭제하거나 느슨하게 바꾸지 않았습니다. 각 실제 부모/자식의 인덱스·값·정확한 배열을 독립 시뮬레이션 결과와 비교합니다.

## 발견한 공통 문제와 실제 결과

1. 시프트 부모는 산식 후보에 없었습니다. 나눗셈과 같은 정규화 경로에 연결했습니다.
2. 완료 순회가 0번 시작만 처리하여 1번 기반 힙의 개수가 미확정이었습니다. base부터 시작하는 완료 구간으로 확장했습니다.
3. DSU는 부모 관계만 있었고 대표 반환·병합 의미가 없었습니다. 자기 자신 종료 예제의 집합은 `[0,1,2,3]`, `[4,5]`, 음수 종료 예제는 `[0,1,2]`, `[3,4]`, `[5]`로 확인합니다. 일반 부모 트리에는 DSU 추천을 붙이지 않습니다.
4. 일반 부모 검사에도 해시 후보가 추천됐습니다. 직접 인덱스 동등 비교와 실제 키 변환을 분리했습니다.
5. 구간 트리는 인덱스 트리까지만 나왔습니다. 실제 집계 출처를 추가하여 루트 `[0,4)`와 갱신 `10→14`, `14→18`을 연결했습니다. 중간 상태는 `stale`입니다.
6. Fenwick은 배열·커서 이동까지만 나왔습니다. 관측된 비트 이동과 구간 집계의 조합으로 0/1번 기반을 구분합니다. 원본 배열의 부분합이나 stride 복사에는 이 추천이 없습니다.
7. 새 의미 상태의 근거·수명·한도·덮어쓰기 경계를 함께 검사합니다. C 사건을 추가하거나 정렬하지 않습니다.

## 검사

정상 종료 C 사례는 16개입니다. 기본 10개와 구조체 DSU, 0번 Fenwick, 인라인 DSU, 힙 할당 구간 트리, 일괄 덮어쓰기, 부분합/stride 반례 6개입니다. 인라인 DSU의 마지막 순환은 그 뒤 따라가지 않는 정상 C 실행이며 구조 조건의 반례입니다.

`tests/ir-priority-partition-range.test.js`는 정확한 구성원·대표·구간·순서·값, 수정 중간 상태, 사용자 지정, 한도와 8개 근거 변조를 검사합니다. 관련 기존 검사만 실행하며 전체 예제는 다시 실행하지 않습니다. 최종 검사 수와 생성 모델 파일 해시는 결과 폴더 `verification.json`에 기록합니다.

최종 결과: 새 검사 10개와 관련 기존 검사 23개, 총 33개 통과·실패 0개입니다. C 사례 16개 모두 정상 종료하고 예상 출력과 일치합니다. 추론 전후 원본 실행 JSON이 같으며 생성 모델 파일 46개 해시도 모두 같습니다. 최초 예상 정정 3건은 위에 별도 기록했습니다. 화면 가독성·애니메이션 검증은 이번 범위에 포함하지 않았습니다.
