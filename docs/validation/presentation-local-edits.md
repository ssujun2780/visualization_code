# 수동 이동의 국소 갱신과 탐색 재현

2026-11-13. 실행 기록과 추론 결과를 유지하면서, 객체·돗자리·도구 이동에 표시 이력 전체를 재생성하지 않도록 수정했습니다. 중간언어 생성·자료구조/실행 관계 추론 코드는 변경하지 않았습니다.

읽은 계약: `presentation.md`, `animation.md` 기본 원칙, `visualization.md` 공간/연결선, `ui.md` 직접 조작, `prepared-scene.md` PS-02·03·06, `pointer-wiring.md` 경로 보존/실패, `moving-tools.md` T-01~04, `loop-navigation.md` L-05. 전체 초기화에 고정 좌표 변경을 포함하던 PS-06은 최신 사용자 합의로 수정했습니다.

검증 전에 고정한 조건: 수동 이동 뒤 기본 이력의 객체·내용·버전 수가 그대로이며 원본 사건 순서를 다시 준비하지 않을 것, 이동·새 장애물에 무관한 경로 점을 그대로 보존할 것, 과거/미래 조회 순서에 관계없이 동일한 시점과 수동 좌표에서 같은 배치·포트를 그릴 것, 오래된 드래그 응답을 적용하지 않을 것입니다. 코드 이름이나 예상 출력에 맞춘 분기는 없습니다.

## 검사

관련 공통 경로 57개 검사 통과, 실패/건너뜀 0개(`test-results/presentation-history/local-edit-tests.log`). 기존 예제 전체를 실행하지 않았습니다. 표시 이력·배선·객체 선택·반복 탐색·재생 경계·도구 배치·공간·트리/포인터 스타일 검사를 사용했습니다. 빌드 통과(`local-edit-build.log`), 기존 편집기 청크 크기 경고는 남습니다.

실제 브라우저에서 같은 376사건 기록과 공유 prepared 결과를 불러와 313으로 이동한 뒤, 포인터로 연결된 구조체 배열의 노드를 드래그했습니다. 이동 직후 313 위치를 유지했고 `aria-busy=false`, 전체 장면 복원 진행 표시 없이 수정된 배열과 연결선이 보였습니다. 이어서 112, 종료 지점 376, 다시 313으로 이동했습니다. 마지막 그리기 위치 313·준비 완료와 수동 좌표/연결선 복원을 확인했습니다. 원본과 동일하게 노드 값은 6·9·6이며 계산은 i<5입니다. 관련 화면은 `test-results/presentation-history/local-edit-moved.png`, `local-edit-restored.png`, 확인 값은 `local-edit-native.json`에 있습니다. 전체 페이지 스크롤 위치가 달라 픽셀 해시 동일성을 주장하지 않습니다. 정확한 좌표·포트·경로 점 비교는 자동 검사로 확인했습니다.

남은 범위: 현재 장면의 기하 비교는 장면 크기에 비례하며 바뀐 영역의 장애물 등록 비용이 있습니다. 고밀도 거대 배선의 최악 시간/메모리는 이번에 측정하지 않았습니다. 원본 상태 조회는 기존 체크포인트/기록 적용을 사용하지만 수동 이동 때문에 기본 배치·배선을 처음부터 진행하지 않습니다. 표현 종류·접기·크기·화면 크기 변경까지 국소화한 작업은 아닙니다.
