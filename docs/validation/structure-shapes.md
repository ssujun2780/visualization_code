# 자료구조별 시각화 검증

2026-11-13. 대상은 시각화와 조회/준비 어댑터입니다. 중간언어 생성·자료구조 분류/추론기는 이번 작업에서 수정하지 않았습니다. 다른 세션의 파일 변경과 추론 성능 감사를 작업 범위에 넣지 않았습니다.

읽고 적용한 계약: presentation, animation의 명령/사건 시간선, visualization의 공간·연결선, ui의 선택/카메라, PS-02·03, SV-01~03, R-01~07. 최신 사용자 합의와 구현은 [SS-01~04](../design/structure-shapes.md)에 정리했습니다.

검사 전에 정한 조건은 원형 큐의 슬롯 고정/커서 이동, 그래프의 원형 정점/방향/가중치, 실제 Union-Find 부모 관계, 원본 값·범위·ID 보존, 미초기화/미확정 정보의 임의 보정 금지입니다.

## 관련 검사

`test-results/structure-shapes/final-tests.log`: **64개 통과**. 형태/간선/속성·저장 기록 통합·기존 World/선택/범위/도구/값 전달 경로만 검사했습니다. 기존 예제 전체를 재실행하지 않았습니다.

저장 실행 검사는 Union-Find 6노드/4부모 간선, 원형 큐 5슬롯, 힙 4노드, 구간 트리 7노드와 구간, 그래프 6정점/9간선 및 가중치를 확인합니다. 큐와 힙의 화면 어댑터 누락을 발견한 뒤 그 사례를 그대로 다시 검사했습니다. 실제 결과에 맞춰 예상 개수나 검사를 낮추지 않았습니다.

가중 그래프는 별도의 렌더러 검증용 C 예제입니다. 예상 출력 `0 10 20 15 30 25 `를 고정한 뒤 한 번 컴파일·실행했습니다. 그 실행의 실제 필드/범위에 **명시적 수동 그래프 역할**을 연결했으며, 이를 자동 추론 성공으로 보고하지 않습니다. 이후 배치 검사는 `--reuse`로 같은 실행을 사용합니다. 분류 규칙이나 파일명별 렌더링 분기는 없습니다.

빌드 로그는 같은 폴더의 `build.log`입니다. 코드 편집기의 기존 큰 청크 경고와 시각화의 동작을 구별합니다.

## 화면과 한계

완성 빌드의 기존 `animation.html`에서 저장 기록을 열어, 원본 코드·중간언어와 같은 공간에 표시되는 모습을 확인했습니다. 화면 검증과 API/단위 검사 통과를 동일하게 취급하지 않습니다. 1280×720 화면에서 유향/수동 무향 그래프 전환, 실제 거리 값/가중치와 1배속 진행, Union-Find의 두 대표와 부모 연결, 원형 큐의 슬롯/커서/관리 필드, 힙의 실제 노드와 연결을 확인했습니다. 증거 화면은 `structures-directed.png`, `structures-undirected.png`, `structures-union-find.png`, `structures-circular-queue.png`, `structures-heap.png`입니다.

구간 트리의 저장 사례는 7개 값과 담당 구간을 표시하지만, 현재 공개 조회가 요구하는 `topologyChildren`이 과거 기록에 없어 간선이 없는 나열로 나타납니다(`structures-range-tree.png`). 과거 집계의 `children` 출처 정보를 현재 부모 관계로 임의 대체하지 않았습니다. 현재 관계가 공급되는 배치 경로와 이 과거 사례의 간선 부재를 구별하며, 해당 사례를 완성된 트리 화면으로 보고하지 않습니다.

미확정 역할·생략 이력·미지원 추론을 화면에서 정답으로 보충하지 않습니다. AVL/RB 회전의 전용 노드 이동 보간, 모든 B트리 계열의 완성된 전용 연출, 임의의 키/색 역할 편집, 매우 조밀한 그래프의 라벨 충돌 해결과 모든 화면 크기/브라우저 검증은 남습니다. 제공된 범위/속성을 그리는 경로와 자동 추론의 완성도를 구별합니다.
