# 배열·구조체 접기와 선택 검증

2026-11-09. 실행 모델은 유지하고 표시 계층·선택·포인터 연결점을 변경했다.

## 규칙

- 배열, 구조체, 중첩 배열·구조체를 개별적으로 접고 펼친다.
- 내부 원소·멤버 선택은 해당 논리 상자의 직접 연결만 강조한다.
- 선 선택은 한 선과 양끝만 강조한다.
- 부모 선택은 자손 전체 선택으로 확장하지 않는다. 접힌 부모를 선의 화면 연결점으로 쓰더라도 같은 규칙이다.
- 같은 주소를 쓰는 컨테이너와 첫 원소·멤버는 포인터의 대상 자료형·크기로 구별한다.
- 접힌 내부끼리의 선은 개수로 표시하고, 외부 연결은 원래 끝점 정체성을 유지한다. 펼치면 복원한다.
- 접기는 실행 값·사건 순서를 바꾸지 않는다. 쓰기 전 화면에 쓰기 후 값이 노출되지 않게 검사한다.

## 자동 검사

`tests/animation-object-selection.test.js`의 8개 검사:

1. 중첩 컨테이너·멤버의 클릭 위치 구분
2. 구조체 주소, 배열 주소, 첫 원소 주소, 다차원 배열의 행 주소 구분
3. 부모 선택 시 내부 선을 강조하지 않는 범위 규칙
4. 접기 후 논리 끝점·값·주변 위치·중첩 자식 설정 유지
5. 접힌 연결점 배선 및 한 선만 선택하는 규칙
6. WRITE 이전 값을 유지하는 표시 경계
7. 완전히 숨겨진 내부 연결만 축약
8. 구조체 패딩이 실제 멤버를 덮어쓰지 않는지 확인

기존 메모리·좌표·배선·값 전달 관련 검사를 함께 실행했다. 전체 C 예제 모음은 다시 실행하지 않았다.

## 실제 실행 기록의 부하 검사

기존 `pointer-network.c`의 정상 실행 기록을 재사용했다. 최대 참조 시점 x2335를 펼침 → 전부 접기 → 다시 펼침으로 검사했다. 컴파일·자료구조 추론 재검증이 아닌 표시·배선 검사다. 아래 시간에는 전체 품질 감사도 포함되며 보장 시간이 아니다.

| 표시 상태 | 실제 참조 | 표시 선 | 숨긴 내부 선 | 배선 연결점 | 미배선 | 상자 관통 | 긴 평행 겹침 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 펼침 | 387 | 387 | 0 | 634 | 0 | 0 | 0 |
| 전부 접기 | 387 | 291 | 96 | 10 | 0 | 0 | 0 |
| 다시 펼침 | 387 | 387 | 0 | 634 | 0 | 0 | 0 |

접점이 늘어난 펼침 상태에서도 경계 통로가 막히지 않도록 돗자리의 배선 여백을 확보했다. 실행 상태가 전후에 동일한지도 검사했다. 기계 판독 결과는 `test-results/pointer-wiring/folding.json`에 저장한다.

## 화면 확인

현재 예제 API의 `pointer-arrays`로 부모 배열 선택, 내부 포인터 상자 선택, 선 선택, 배열 접기 및 내부 구조체 하나만 접기를 직접 확인했다. 부모 선택 시 내부 선들이 흐려지고, 내부 상자 선택 시 해당 선과 반대편만 강조되는 것을 확인했다.

## 재현

```powershell
node --test tests/animation-object-selection.test.js tests/animation-world.test.js tests/animation-memory.test.js tests/animation-pointer-wiring.test.js tests/animation-transfer-phases.test.js
node scripts/animation/verify-folding.mjs test-results/pointer-wiring/pointer-network.json
```

`verify-folding.mjs`의 입력은 schema 3의 plan·trace를 함께 담은 실제 실행 기록이다. 대규모 배열의 아직 관찰되지 않은 부분을 전부 확장하는 기능이나 자료구조 추론 방식은 이번 변경에 포함하지 않는다.
