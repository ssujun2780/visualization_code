# 준비된 자료구조 표현 고정

2026-11-13. 사용자 지적에 따른 PS-02·03 보완입니다. 중간언어 생성·자료구조 추론은 수정하지 않았습니다.

## 원인과 변경

이전 구현은 `view` 이름만 고정했습니다. 원형 여부는 시점별 `logicalOrder` 등으로 다시 결정했고, 표시할 노드가 없으면 일반 상자 그리기로 돌아갔습니다. 실제 저장 큐 기록의 표현 이력에서 `circular=false/true`가 함께 나왔습니다. 전체 실행·분석이 끝났다는 사실만으로 고정 표현 계약이 구현된 것은 아니었습니다.

| 계약 | 변경 위치 | 검증 근거 | 남은 항목 |
| --- | --- | --- | --- |
| PS-02 종류·도형 고정 | `prepared-appearance.js`, `prepared-structures.js`, `prepared-state.js` | 전체 준비 이력에서 모양·방향·서브타입·표시 슬롯을 한 번 정함. 빈 큐와 재점유·역방향 탐색에서 같은 원형 좌표 | 추론 결과 자체의 정확성은 별도 |
| PS-03 관계 부재에도 표현 유지 | `structured-memory.js` | 관계 없음·이력 생략에도 정해진 트리와 칸 유지. 미래 간선을 표시하지 않음 | 관계 이력 부족은 보충하지 않음 |
| 실제 시점의 값·속성 보존 | 같은 경로 | 배치용 노드의 미래 라벨·색·높이·구간을 현재 속성으로 사용하지 않음. 원본 값·범위·ID 유지 | 모든 자료구조 구현 방식의 검증은 아님 |
| 고정 슬롯 | `prepared-appearance.js`, `structured-memory.js` | 표시 창에 일부 칸이 추가되어도 기존 배열 원소의 인덱스/위치 유지 | 거대 구조의 모든 원소 동시 표시는 기존 한도 적용 |
| 과거 기록 호환 | `PreparedStructures` 생성 시 준비 | 저장 기록을 바꾸거나 추론을 다시 실행하지 않고 모양 한 번 준비 | 이전에 이미 열린 페이지는 새로고침 필요 |
