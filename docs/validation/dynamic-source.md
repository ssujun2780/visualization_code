# 직접 작성한 코드 연결 검증

2026-11-11. 기존 Monaco 편집기 → 소스 스냅샷 전달 → 실행 세션 API → 기존 중간언어/애니메이션 경로를 연결했습니다. 모델과 추론기는 변경하지 않았습니다.

검증 전에 예상한 통합 코드 과정: 입력 3 → 세 Cell을 calloc → 값 [1,2,3]과 next 연결 → 포인터 배열로 첫/마지막 원소 참조 → adjust 함수에서 3 미만에 2 추가 → 값 [3,4,3], 합 10 반환 → 배열과 문자열을 통해 `total=3:3:10` 출력 → free와 종료.

`tests/animation-custom-source.test.js`에서 실제 API 결과와 위 예상을 비교했습니다. 입력 대기 전후 runId와 앞선 사건이 동일하며, 원본 소스 보존·40KiB 소스·잘못된 요청·컴파일 실패·런타임 중단도 확인했습니다. 기존 입력/오류 검사와 함께 17개 통과, Vite 빌드 통과. 기존 예제 전체는 재실행하지 않았습니다.

브라우저에서는 등록된 예제가 아닌 편집기의 통합 코드를 전달하여 입력 대기(12개 기록), 입력 3 이후 215개 기록과 `count?\ntotal=3:3:10\n` 출력을 확인했습니다. 검증에 사용한 임시 편집 내용은 원래 작성되어 있던 코드로 복원했습니다.
## 같은 페이지 직접 입력

시각화 페이지에 기존 Monaco 편집기를 연결했습니다. 브라우저에서 직접 붙여넣기·Ctrl+Enter 실행 → scanf 입력 대기 → 입력 5 → 함수의 두 배 연산과 +3 → 출력 `13`, 35개 기록을 확인했습니다. 편집기를 고쳐도 이전 실행의 출력·원본은 유지되며, 미정의 변수를 실행하면 즉시 컴파일 오류와 2행 강조, 편집기 진단을 표시했습니다. 관련 API 검사 4개와 빌드를 통과했습니다. 이번에는 모델·추론기를 변경하지 않았습니다.
