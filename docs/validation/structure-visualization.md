- `scripts/animation/audit-structure-views.mjs`가 12개 균등 prefix와 출력 시점, 시점당 최대 12개 실제 살아 있는 객체를 조회합니다. 각 논리 필드는 원본 할당 내부이며, 값은 현재 장면에서 가져옵니다. 원본/추론 지문을 전후 비교합니다.
- 여러 단계에서 후보가 달라지는 경우와 자동 인식 누락은 통과로 숨기지 않고 [문제 기록](../../test-results/structure-visualization/problems.md)에 구분했습니다. `audit.json`의 passed는 표시 계약 검사 결과입니다.

실행 로그: `test-results/structure-visualization/final-tests.log` 24개 통과, `final-shape-tests.log` 최종 관련 4개 통과. `audit.json`은 **17개 기록(저장 11·새 컴파일 6), 1,273회 조회, 771개 도형 스냅샷**의 계약 검사를 통과했습니다. 이 수는 고유 자료구조의 개수가 아닙니다. 자동 추천 15종을 소비했지만 모든 세부 렌더러의 완성을 의미하지 않습니다. 마지막 수동 그래프·별칭 보완은 `audit-focused.json`에 별도로 확인했습니다.

Node에서 자동 시점 조회·현재 값 투영의 관측 최댓값은 약 39.6ms, 큰 포인터망의 수동 그래프 조회는 약 9~31ms였습니다. 초기 추론 준비는 별개이며 큰 기록에서 약 17~24초 걸렸습니다. 브라우저 프레임 성능이나 모든 컴퓨터에서의 상한을 보장하지 않습니다. `canonical-inference-performance.json`, `audit.json` 참고.

`model-inference-preservation.json`: 시작 시점의 143개 파일과 비교해 생성 모델 변경은 없었습니다. 추론기 6개 파일의 별도 변경을 감지했으며 이번 연결 작업에서 편집하지 않고 유지했습니다. 전체 작업 공간이 처음과 완전히 같다는 주장과 구별합니다.
