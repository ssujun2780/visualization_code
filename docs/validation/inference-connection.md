# 자료구조 추론기 연결 점검

2026-11-13. 최초 점검 범위는 실행 결과 → 추론 결과 → 고정 표현 준비 → 기존 화면입니다. 최초 연결 점검에서는 추론 분류·추천 규칙과 중간언어 생성을 변경하지 않았습니다. 연결 계약(SV-01·02, SS-01, PS-02)과 추론/생성 분리 계약을 적용했습니다. 이후 승인받은 추론 수정 결과는 문서 마지막에 별도로 기록했습니다.

## 확인 경로

`test-results/inference-connection/check.mjs`는 실제 세션 API 처리기와 실행·분석 Worker를 호출합니다. 루프백 소켓은 실행 샌드박스의 EACCES로 사용할 수 없어 요청/응답 전송만 메모리 스트림으로 대체했습니다. 실행·추론 결과를 모의 값으로 대체하지 않았습니다. 브라우저가 요청하는 최신 공통 정의 형식(`EXECUTION_ACCEPT`)으로 직렬화하고 `decodeExecution`으로 복원했습니다.

준비된 화면 캐시·수동 역할 없이 네 사례를 실행했습니다. 모두 API 200, 실행/추론 `completed`, 동일한 programId/runId, 원본 계획·기록·추론의 해시 불변, 재생 종류 고정을 확인했습니다. 처리기 응답은 약 1.5~2.2초, 표현 준비는 약 4~273ms였습니다. 전 규모의 성능을 뜻하지 않습니다.

| 사례 | 소스 기준 기대 | 최초 점검 당시 자동 결과 | 구분 |
| --- | --- | --- | --- |
| 트리 삽입·순회 | BST 7노드·6간선 | BST 7노드·6간선, 관계 이력 25개 | 정상 연결 |
| 인덱스 인접 그래프 | 5정점·6저장 간선 | 배열·부분 연결 리스트/트리 등으로 추천 | 공개 추론/추천 단계에서 전체 인접 그래프가 선택되지 않음 |
| 포인터 그래프 | 5정점·10저장 연결 | 부분 배열이 자동 추천 1위, 그래프는 대안으로 존재 | 공개 추천 순위/범위 문제. 화면에서 임의로 정답 그래프로 바꾸지 않음 |
| 스택·큐 | LIFO 스택, FIFO 큐 | 스택은 인식, FIFO는 배열로만 추천 | FIFO 후보/추천은 추론 측 미해결 |

## 실제 화면 확인

실제 API 응답의 plan/trace/workAnalysis를 열어 준비 캐시 없이 화면에 연결했습니다. 스택은 현재 값 9 읽기와 세로 배치를 확인했습니다. 같은 BST 응답의 추론 sidecar만 공식 공유 저장 형식으로 변환한 입력에서도 600/714의 원본 코드·노드·부모/자식 선·읽기 강조가 표시됩니다. 수동 자료구조 지정은 사용하지 않았습니다.

화면 근거: `inference-connected-stack.png`, `inference-connected-tree.png`. 화면 한 장에 모든 노드가 동시에 보인다는 검증과 구별하며, 실제 7노드·6간선 개수는 준비/World 결과에서 대조했습니다.

추론/추천 측 세 사례의 미해결 항목은 위 표와 `report.json`에 남겼습니다. UI의 자동 추천 덮어쓰기나 예제별 분기를 추가하지 않았습니다. 다른 세션에서 바뀌는 추론 파일의 전체 정확성·No43의 기록 한도·대규모 성능은 이번 점검의 완료 항목으로 보고하지 않습니다.

## 최신 연결 재점검 — 2026-11-13

후속 사용자 재현: **No43은 자료구조 재생 준비 시간 초과로 실패하며 아직 미해결**입니다. 아래 네 사례의 성공과 구별합니다. 현재 원본 실행은 정상 완료했지만 서버 분석 제한 후 브라우저 재추론이 이어지는 경로는 [별도 조사](no43-preparation-timeout.md)에 기록했습니다.

위 최초 점검의 그래프·FIFO 미해결 판정은 후속 추론 수정 전의 이력입니다. 최신 공통 API 처리기를 실제 실행 Worker와 분석 Worker에 연결하여 네 사례를 새로 실행했습니다. 셸의 루프백 소켓 제한 때문에 외부 HTTP 소켓 대신 같은 미들웨어의 요청·응답 스트림을 사용했으며, 실행·추론을 모의하지 않았습니다. 현재 결과는 다음과 같습니다.

| 사례 | 최신 추론 및 화면 준비 결과 |
| --- | --- |
| BST | 7노드·6간선, 관계 이력 25개 |
| 인덱스 인접 그래프 | 5정점·6간선, 관계 이력 10개. 그래프는 한 번 표시하고 인접 저장 배열은 원본으로 유지 |
| 포인터 그래프 | 5정점·10연결 |
| 스택·큐 | 각각 stack·queue, FIFO 큐 추천 정상 |

새 인덱스 그래프 후보에는 관계 스냅샷이 있었으나 기존 범용 조회기가 해당 후보 종류를 투영하지 않아 화면에 간선이 전달되지 않았습니다. 이번에는 **화면 소비 경로만** 보완했습니다. `scripts/model/`과 `scripts/inference/`의 실행·추론 코드는 변경하지 않았습니다.
