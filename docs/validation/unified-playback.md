# 같은 공간의 사전 준비 재생 검증

2026-11-13. 요청 범위는 실행·분석 완료 후 재생, 자료구조와 연산의 원본 공간 통합, 재판정/창 재생성에 따른 깜빡임 제거입니다. 모델·추론기 구현은 이번 작업에서 수정하지 않았습니다. 전체 예제를 재실행하지 않았습니다.

읽고 적용한 계약: `presentation.md`, 애니메이션의 명령/사건 시간선, 시각화의 소속·수명·원본 정체성, UI의 카메라/입력, 표현 정책 1~6, SV-01~04, 실행 관계 R-01~07. 최신 사용자 합의로 별도 패널과 재생 중 표현 선택을 PS-01~04로 대체했습니다. 추론·조회 API는 유지합니다.

검증 전 고정 조건: 재생 활성화 전에 준비 완료; 아직 생성되지 않은 객체 없음; 값·참조는 현재 기록; 같은 필드 ID로 전달선 연결; 트리 7노드 및 중첩 포트 접근; 격자 12칸; 배열 복사와 알루가 같은 공간에 표시; 속도 1×; 입력은 같은 실행 유지. 소스의 예상 출력과 기록 출력을 비교하며 추론 정답을 출력에 맞춰 만들지 않았습니다.

## 실행한 관련 검사

- `focused-final.log`: 준비 장면·World·도구 배치·객체 선택·범위 포커스·Playback 39개 통과.
- `input-final.log`: 입력 세션 5개 통과.
- `transfers-final.log`: 공통 전달 연산 1개 통과. 이전 검사는 숨긴 컴파일러 상수에도 화살표를 요구했습니다. 미표시 끝점이 실제 static constant 보조 저장소임을 별도로 확인하고, 나머지 모든 끝점·원래 인덱스·선 충돌·숫자 내용 보호 검사를 유지했습니다. 실제 객체의 누락을 허용하지 않습니다.
- `build-final.log`: 빌드 통과. 기존 코드 편집기 큰 청크 경고가 남습니다.

로그는 `test-results/unified-playback/`에 있습니다. 테스트 통과와 화면 가독성 확인을 구별합니다. 실제 화면은 완성 빌드 미리보기에서 트리·배열 이동/비교를 1×로 재생했습니다. 개발 서버는 다른 세션의 소스 변경 때문에 재로딩되어, 이를 재생 자체의 깜빡임과 구별했습니다.

작업 시작/완료 해시 비교에서 모델 파일은 동일했고 추론 파일 10개가 다른 세션 작업 중 변경되었습니다(`model-inference-after.json`). 이 작업의 편집은 화면·준비 어댑터·입력 세션 상위 제어와 관련 문서/검사에 한정했습니다. 추론 파일을 되돌리거나 이번 변경으로 덮지 않았습니다.

남은 한계는 `test-results/unified-playback/problems.md`와 PS-04를 참고합니다. 전체 35개 이상 예제·모든 자료구조·모든 화면 크기를 검증한 결과가 아닙니다.
