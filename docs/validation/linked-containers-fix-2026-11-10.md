# 연결 리스트 계열 7개 보완 검증

2026-11-10. [수정 전 감사](linked-containers-audit-2026-11-10.md)의 예상·소스·plan·trace는 유지하고, 공통 추론기만 수정했습니다. [공통 설계](../design/linked-container-inference.md)에 규칙과 메타데이터를 설명했습니다.

## 수정 후 실제 결과

| 항목 | 확인 결과 |
|---|---|
| 1. 미호출 함수의 증거 승격 | 조회 표 반례에서 목록 추천 제거. 나중에 실행할 순회 근거도 이전 시점으로 새지 않음 |
| 2. 포인터 시작 슬롯 범위 | 공유 노드 없는 두 목록에서 `roots[0]`·`roots[1]` 각각 정확한 후보가 우선됨. 32/64비트 슬롯 크기 검사 통과 |
| 3. 미확인 연결의 완전성 | 마지막 링크 `unknown` 유지. 다른 투영 경로에서도 완전한 목록/트리 추천으로 승격하지 않음 |
| 4. 더미 노드 구성원 | 물리적 노드 3→1, 데이터 노드 2→0으로 별도 기록. 목록 추천의 표시 개수는 2→0 |
| 5. 원형 목록 | 데이터 머리를 포함한 고리를 `linked-list / circular`로 추천. 꼬리가 고리에 진입하는 반례는 단순 원형 목록으로 판정하지 않음 |
| 6. 인덱스 시작점 | 레코드·분리 배열·표·사용/빈 슬롯 목록에서 시작 변수별 식별자·순서·경계 일치. `[6,2,5]→[6,5]` 이후에도 전역의 실제 `2→5`는 보존 |
| 7. 연결 방식의 동작 정책 | 연결 큐가 queue로 추천됨. 노드 식별자 기반 FIFO/LIFO/양끝 조작 구분. 단일 원소·대량 교체·재배열 반례 통과 |

20개 기존 실행 기록을 재추론하여 **원래 검사 50/50**, 별도 시작점 선택 **2/2**가 통과했습니다. 새 인덱스 시작점 후보에서도 기대 순서와 종료 상태를 직접 검사했습니다. 검사기가 전역 간선을 따라갈 수 있다는 사실만으로 통과시키지 않았습니다.

## 관련 검사

- 기존 연결 시작점·컬렉션·역할 topology·저장 근거·레코드 인덱스·경계·추천 검사: **38/38**. 기존 기준은 수정하지 않았습니다.
- 최종 추천 정책 검사: **9/9** 재확인. 위 기존 38개에 포함되는 항목이므로 별도 성공 개수로 중복 계산하지 않습니다.
- 저장된 실행 기록의 재추론과 C API 실행을 구분했습니다. 관련 없는 예제 전체나 UI 검사는 실행하지 않았습니다.

검사 명령과 로그는 `test-results/linked-containers-fix-2026-11-10/`의 `compare.mjs`, `verify.mjs`, `summary.json`, `focused-tests.txt`, `related-tests.txt`, `final-presentation-tests.txt`에 있습니다. 사례별 `inference.json`과 `comparison.json`을 수정 전 산출물과 별도 저장했습니다.

## 변경 경계

이 작업의 기존 코드 변경은 `linked-views.mjs`, `structure-storage.mjs`, `structure-presentation.mjs`, `structure-inference.mjs`, `structure-overlay-contract.mjs` 5개이며, `indexed-root-views.mjs`와 `linked-container-policy.mjs`를 추가했습니다. 중간언어 생성 코드를 수정하지 않았습니다.

기준 파일 228개를 해시로 대조했습니다. 위 5개 이외에 이번 작업에서 수정하지 않은 `scripts/animation/example-api.mjs`, `scripts/instrumentation/toolchain.mjs`의 동시 변경이 감지됐습니다. 후자는 실시간 입력 공급자 지원 변경입니다. 두 파일은 되돌리거나 편집하지 않았고, 당시 해시를 `summary.json`의 `externalChanges`에 별도 기록했습니다. 나머지 221개 기준 파일과 기존 검사는 그대로였습니다. 따라서 저장소 전체가 불변이었다고 주장하지 않습니다.

이번 변경은 예제 번호·변수명·특정 출력값을 분기로 사용하지 않습니다. 자료형·부분 객체 범위·실행 식별자·실제 값 전달 경로·시점별 노드 연결을 공통 근거로 사용합니다. 다만 작성자의 의도나 모든 미관측 실행에 대한 완전성을 보장하지 않습니다. 상위 5개는 향후 우클릭 메뉴의 추천이며, 사용자 지정 우선과 불확실성 표시는 유지합니다.
