# 공통 정의 분리 구현·검증

사용자 승인 범위: 자료형·표현식·코드 위치의 반복 설명을 공통 정의로 분리하고, 실행 기록과 자료구조 추론 결과를 구분합니다. 저장/전송 복원 후 기존 결과가 유지되어야 합니다. 생성 모델의 의미와 추론 규칙, 관찰 한도는 변경하지 않습니다.

읽은 계약은 `presentation.md` 모델/화면 경계, `c-model.md` CLI·자료형·출처, `execution-visualization.md` 상세 기록, `inference-model.md` 생성/추론 분리입니다. 새 저장 계약은 `execution-storage.md` EF-01~04에 정리했습니다. 화면 구현 내용은 입출력 연결로 제한하며 배치/애니메이션을 변경하지 않습니다.

| 계약 | 공통 구현 위치 | 확인 근거 | 남은 범위 |
| --- | --- | --- | --- |

## No43 결과

기존 진단 파일을 고정 입력으로 사용했습니다. 소스 SHA-256은 현재 No43과 일치합니다. C를 다시 실행해 다른 결과에 맞춘 것이 아니라, **동일한 저장 기록**을 분리하고 복원해 전체 값을 비교했습니다.

단위 MB는 1,000,000바이트입니다. 아래는 각각 공통 정의를 포함한 번들 파일 크기이며, JSONL 중복 사본과 선택적 원시 관찰을 공개 기록에 합산하지 않았습니다.

| 자료 | 기존 서식 JSON | 기존 공백 없는 JSON | 새 공통 정의 형식 | 사건 수 |
| --- | ---: | ---: | ---: | ---: |
| 공개 계획 + 실행 | 84.39 MB | 38.53 MB | **19.86 MB** | 11,872 유지 |
| 원시 관찰 계획 + 실행 | 41.19 MB | 22.40 MB | **15.24 MB** | 26,571 유지 |

공개 기록은 기존 파일 대비 약 **76.5%**, 기존 공백 없는 내용 대비 약 **48.5%** 작아졌습니다. 공개 정의 6,017항목, 원시 정의 1,664항목입니다. 같은 사건을 병합하거나 실행 이력을 삭제하지 않았습니다. 공개 전체 복원 SHA-256은 `111f0c574d556c664065b03707025db402e59d15bbdf01f5e878e2a437290b17`, 원시 전체는 `60bdcab8c4d199a947cc70da1e9ce64e400cc078bf4b6ffdc5fd805d5660671f`로 전후 일치합니다.

공개/원시 기록을 같은 디렉터리에 저장한 실제 파일: definitions 1,915,264바이트, plan 2,759,382바이트, trace 15,247,261바이트, observations.plan 1,387,427바이트, observations.trace 13,760,718바이트입니다. 다섯 파일 합계 35,070,052바이트이며 JSONL은 별도 사본 13,550,025바이트입니다.

No43의 `limited` 및 `trace-size-limit`은 유지됐습니다. **내부 16 MiB 관찰 한도를 해결하거나 전체 실행을 완료시킨 수정은 아닙니다.** 관찰 예산을 공유 저장 비용에 맞추는 작업은 별도입니다.
