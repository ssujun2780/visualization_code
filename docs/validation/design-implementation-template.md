# 설계와 구현 대응표 템플릿

**현재는 절차 문서이며 자동 검사 도구를 구현한 것이 아닙니다.** 실제 작업별 기록에 아래 항목을 채웁니다. 읽은 문서, 적용 조항, 변경과 검사 결과의 연결을 검토할 수 있게 남깁니다.

## 작업 범위와 적용 계약

- 사용자 요청과 제외 범위:
- 실제 읽은 문서·관련 절/조항 ID:
- 적용 상태: 필수 조건 / 승인된 초안 / 미정 사항
- 기존 구현과의 차이, 이번 변경이 필요한 공통 경로:
- 검증 전 고정한 입력·예상 결과·관계·화면 조건:

| 조항 ID 또는 문서 절 | 구현 위치/변경 내용 | 검증 근거 | 상태와 남은 문제 |
| --- | --- | --- | --- |
| 예: R-02 | 작성 예정 | 원본 기록 불변 및 명령 연결 검사 예정 | 미구현 |
| 예: R-03 | 작성 예정 | 선택/서랍 사용 중 실제 재생 유지 확인 예정 | 미구현 |
| 예: R-05 | 작성 예정 | 관련 배열·변수·연산·코드가 함께 보이는 재생 화면 확인 예정 | 미구현 |

## 완료 판단

- 요구 조항 중 이번 범위의 항목이 빠지지 않았는가?
- 예제 전용 분기 없이 공통 경로에 반영됐는가?
- 예상/실제/반례를 구별했고 실패 검사를 약화하지 않았는가?
- 사용자 동작·가독성 요구를 실제 화면에서 확인했는가?
- 미구현·미검증·실패·범위 밖 항목과 다음에 필요한 근거를 명시했는가?

테스트 수·빌드 성공·한 장면의 정상 출력만으로 전체 설계 준수를 선언하지 않습니다. 조항에 연결된 구체 근거를 기록합니다. 실제 설계와 다른 동작을 의도했다면 그 차이를 문서와 보고에서 숨기지 않습니다.
