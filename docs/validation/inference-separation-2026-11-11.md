# 생성·추론 모델 분리 검증

후속: 아래 남겨 둔 두 실패는 [평가 순서·중단 WRITE 보완](evaluation-limit-fixes-2026-11-11.md)에서 처리했습니다. 이 문서의 집계는 분리 직후 상태이며 당시 기록을 유지합니다.

대상은 모델 경계, 기존 추론 규칙 유지, 공개 API·CLI 호출부입니다. 자료구조 판별 범위를 새로 확장하지 않았으며 전체 예제 집합은 재실행하지 않았습니다.

## 결과

- 추론 전용 구현 47개와 추론 검증기를 `scripts/inference/`로 옮겼습니다. 생성 관찰기에 남아 있던 레코드 참조 묶기·위상 판정도 추론으로 이동했습니다.
- 이동한 규칙 중 진입점 외 46개는 가져오기 경로를 정규화한 해시가 작업 시작 시점과 같습니다. 진입점은 실행 식별자 검증·결과 범위 표기·옮긴 관계 수집 연결만 변경했습니다.
- 분리 전 보관한 복합키 사례 909개 사건·27개 추론 결과와 VLA 사례 139개 사건·0개 추론 결과를 비교했습니다. 전체 직렬화된 중간언어와 추론 메타데이터가 같았습니다. 신규 `scope` 속성만 별도 검증했습니다. VLA의 0개 결과는 분리 전부터 같았으며 지원 완료 판정이 아닙니다.
- 경계 검사 6개가 통과했습니다. 상호 구현 의존성 금지, 자동 추론 제거, 입력 불변성, 다른 실행의 결과·보조 자료 거부, 추론 실패·시간 초과 격리, 선택적 파이프라인, 저장 기록만 사용하는 CLI를 포함합니다.
- 관련 기존 검사 35개 중 33개가 통과했고 아래 2개는 미통과로 남겼습니다. 실패 기준을 완화하지 않았습니다. 총 고유 검사 41개 중 39개 통과입니다.
- 실제 `trace-model.mjs` → `infer-structures.mjs` CLI 연결은 완료됐습니다. 기본 산술 예제는 14개 사건·3개 객체이며 자료구조 추론 후보는 0개입니다.
- 실행 없이 로컬 JS 가져오기 경로 587개를 확인했습니다. 원본 계획·실행 JSON을 추론 CLI가 수정하지 않는지 별도로 검사했습니다.

## 남겨 둔 검사 문제

1. `ir-partial-limits.test.js`: 기록 바이트 한도에서 중단된 `x145 WRITE`는 `phase: incomplete`이며 완료값 `value`가 없습니다. 기존 검사가 모든 WRITE에 `value.decimal`을 요구하여 실패합니다. 이전 관찰기 방식의 관계 묶음을 복원해 재변환해도 중간언어가 동일했습니다. `ir-record.mjs`·`core.mjs`의 해시는 작업 시작 시점과 같습니다. 검사나 기록 계약은 수정하지 않았습니다.
2. `model.test.js`의 900줄 정규식 예제: 추론 전 계측 LLVM 컴파일에서 `%__cvm_evaluation_68`이 정의되지 않은 phi 입력으로 참조되어 실패합니다. 컴파일·평가 순서·중간언어 계획/기록 구현의 해시가 작업 시작 시점과 같습니다. 이번 분리와 별도로 평가 순서 변환을 조사해야 하며, 통과로 처리하지 않았습니다.

원시 관찰의 구조 메타데이터를 검사하던 기존 검사 3개는 명시적으로 추론을 실행하고 동일한 연결·순환 조건을 `inference.structures`에서 검사하도록 옮겼습니다. 이름 변경 불변성 검사에는 빈 결과끼리 같다고 통과하지 않도록 비어 있지 않다는 조건도 추가했습니다. 나머지 원시 관찰 검사는 생성 모델만 사용합니다.

초기 가져오기 확인 명령의 이름 필터가 적용되지 않아 범위 밖 검사가 시작됐고 중단했습니다. 그 부분 로그는 완료된 검증으로 계산하지 않았습니다. 이후 검사는 파일 목록 또는 셸 해석을 거치지 않는 인자 배열로 한정했습니다.
