# 실행 중 공통 정의 공유와 선택 출력 검증

후속 확인: 아래 No43 수치는 **컴파일·기록 완료** 근거입니다. No43의 전체 자료구조 재생 준비 완료까지 보장한 결과가 아닙니다. 실제 180초 준비 오류의 원인·수정·Worker 완료 측정은 [별도 검증](no43-preparation-fix-2026-11-13.md)에 기록합니다.

## 범위와 고정 기준

읽은 계약: `presentation.md` 모델/화면 경계, `c-model.md` 상세 기록·실행 제한, `execution-visualization.md` 관찰 기반 작업과 저장 경계, `inference-model.md` 생성/추론 분리, `execution-storage.md` EF-01~04.

사건을 생략하거나 값을 합치지 않고, 관찰 바이트 비용과 저장 표현을 개선했습니다. C 컴파일·계산 묶음·추론 규칙은 변경하지 않았습니다. `recorder.mjs`의 기록 입구와 공통 저장 계층을 수정했습니다.

수정 전에 동일한 No43을 기존 기록기로 실행하되 비교 기록 확보용으로만 64MiB 예산을 적용했습니다. 수정 후에는 기본 16MiB 예산을 사용했습니다. 두 실행의 계획·공개 중간언어·원시 관찰 전체와 stdout/stderr를 비교합니다. 서로 다른 실행의 runId 및 명시적으로 바뀐 예산 coverage 항목만 제외하고 사건 ID·순서·값·입력·대상·출처·수명·나머지 coverage는 동일해야 한다고 고정했습니다. 기존 사례 전체는 재실행하지 않았습니다.

## No43

| 항목 | 수정 전 정상 종료 기준 | 수정 후 |
| --- | ---: | ---: |
| 비교 실행의 설정 예산 | 64MiB | 기본 16MiB |
| 생성 시점 관찰 비용 | 42,414,437바이트 | **14,845,083바이트** |
| 공개 중간언어 사건 | 29,474 | 29,474 |
| 원시 관찰 사건 | 65,636 | 65,636 |
| 종료 | completed / 0 | completed / 0 |
| 계획·공개 기록·원시 기록 전체 차이 | 기준 | **없음** |

관찰 비용 약 65% 감소입니다. 과거 기본 한도에서 중단된 11,872개 공개 사건과 비교해 같은 사건 수라고 주장하는 것이 아닙니다. 이번에는 **완료된 전체 실행**을 비교했습니다. 전체 파일 크기와 사건 생성 시점 비용도 구별합니다.

수정 후 공개 계획/기록과 원시 계획/기록, 공통 정의를 모두 저장한 다섯 파일은 40,748,889바이트입니다. JSONL 중복 사본은 기본으로 생성하지 않습니다. 완료 근거·객체/프레임 상태·계획도 포함하므로 14.85MB 관찰 예산 수치와 같지 않습니다.

공유 정의의 실제 객체 정체성 및 런타임 값의 독립성은 검사했습니다. 프로세스의 최대 RAM 감소율은 측정하지 않았으며, 현재도 전체 사건을 메모리에 유지합니다.

## 관련 검사와 화면 제약

관련 5개 검사 파일의 **24개 통과**: 저장 형식 7, 관찰 저장 3, 실제 CLI/HTTP 통합 4, 부분 기록/한도 4, 생성·추론 분리 6. 기존 부분 기록/중단 기대값과 추론 검사 기준은 유지했습니다. JSONL 검사 호출에는 새 선택 옵션을 명시했습니다.

`--jsonl` CLI 인자 추가 후 해당 통합 검사 4개를 다시 통과했습니다. Vite 빌드도 통과했고 기존 큰 청크 경고는 유지됩니다. 저장된 전후 전체 기록에 대해서도 undefined·특수 값을 지우지 않는 엄격 비교를 별도로 통과했습니다(`strict-comparison.log`).

내장 브라우저에서 로컬 Vite 접속이 `ERR_CONNECTION_TIMED_OUT`으로 실패했습니다. Firefox 대체 확인은 도구가 Windows 브라우저 URL 정책 미지원으로 중단하여 더 조작하지 않았습니다. 화면 가독성·파일 선택·입력 재개 UI를 통과했다고 주장하지 않습니다. 파일 복원과 실제 HTTP 세션의 동일 runId/접두 사건 보존·최종 출력은 자동 검사로 확인했습니다.
