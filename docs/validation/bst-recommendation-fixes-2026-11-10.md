## 변경

1. `structure-presentation.mjs`: 같은 현재 루트에서 관측된 연결 배열 역할을 공유하는 후보들의 범위를 비교합니다. 겹치는 coindexed 후보도 포함하되, 부가 값 배열만 공유하는 독립된 관계는 합치지 않습니다. 원래 후보는 그대로 두고 가족 크기·누락 수만 일관되게 계산합니다.
2. `structure-storage.mjs`: 포인터 대상은 pointee 범위로 좁히고, 연결 구조의 간접 조회는 현재 도달 구성원으로 판단합니다. 다른 NULL 자식 슬롯, 과거 대상, 인접 레코드의 후보를 선택 범위에 끼워 넣지 않습니다. 직접 선택한 빈 슬롯·비워진 컨테이너·센티널·배열 보기는 유지합니다.
