2026-11-12.

## 범위와 적용 계약

- 요청: ‘작업 연결 · 재귀·구간 복사’에서 미해결 근거만 나오고 내용을 볼 수 없는 문제 수정.
- 읽은 계약: presentation의 모델/추론 경계, animation 기본 원칙, visualization 공간과 대상, ui 화면과 조작, work-context-view 표현/시점, 실행 관계 R-03~R-05·E-07~E-09.
- 필수 조건: 실제 저장소·값·수명·명령 순서 유지. 예제명/변수명/정답 분기 금지. 생성 모델·자료구조 추론기·실행 관계 판정/공개 조회 API 변경 제외.
- 원인: 현재 활성화의 접근 누적만으로 배열을 고르므로 호출 진입에서 호출자 배열이 사라짐. 스칼라는 제목에만 몰리고 본문은 비어도 빈 상태가 안 나옴. 미해결 출처는 개수만 제공.
- 검증 전 기대: 재귀 진입에서도 main 소유 원본 배열 2개 유지, 부분 쓰기는 실제 도착 이후에만 갱신, 앞 시점으로 이동하면 이전 값 복원. 출처 누락과 조회 실패를 구별하고 근거 사건을 표시.

## 남은 근거

후속 수정: 사용자 승인으로 [주소 출처 계약 보완](address-origin-contract-fix.md)을 적용했습니다. 아래는 그 이전 UI 수정 당시의 잔여 항목이며, 새 실행 기록에서는 해당 네 사건의 경고와 매개변수 주소 전달 누락을 해결했습니다. 기존 저장 기록은 자동 변환하지 않습니다.

기존 work-merge 분석의 `unresolved-value-operand`, `unresolved-callee-operand` 자체는 이번 UI 수정으로 제거하지 않았습니다. 관측된 배열/값/참조가 있는데도 보기에서 제외한 문제와, 안내가 근거를 노출하지 않은 문제를 고쳤습니다. 추후 출처 그래프의 결손을 보완할 경우 별도 모델/분석 범위에서 검증해야 합니다.
