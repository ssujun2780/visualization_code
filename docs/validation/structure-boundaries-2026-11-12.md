## 실제 검사 결과

- 새 입력 **21개 모두 정상 실행**, 고정한 출력 일치. 기본 16개와 변형 5개입니다.
- 새 경계 검사 12개, 기존 확장 관계 검사 14개, 생성/추론 분리 검사 6개: 최종 **32/32 통과**.
- 별도로 관련 기존 우선순위·대표·구간 검사 **10/10 통과**. 기존 예제 전체는 재실행하지 않았습니다.
- 수정 중 기존 높이 역할 사례에서 `steps`가 없는 CALC를 읽는 오류가 드러났습니다. 공통 분석 경로에서 선택적 메타데이터를 처리하도록 고쳤고 관련 회귀 검사를 재통과했습니다.
- `verification.json`에 21개 실행 상태·출력·사건 수와 모델 파일 해시 비교 결과를 남겼습니다.

재현: `node --test tests/ir-structure-boundaries.test.js tests/ir-structure-extensions.test.js tests/inference-separation.test.js`. 원본 기록은 캐시로 재사용하고 추론은 현재 코드로 다시 실행합니다. `scripts/experiments/structure-boundaries-audit.mjs`는 16개 기본 사례의 추론 결과만 갱신합니다. 초기 고정 기록을 다시 만들기 위한 `--capture`는 기존 기록 덮어쓰기를 허용하지 않습니다.

## 남은 항목

- 포인터 인자 비교자 예제는 복합키 `[첫 필드 오름차순, 둘째 필드 내림차순]`을 확인하지만, 호출을 가로지르는 힙 인덱스 관계·활성 범위는 아직 확인하지 못합니다. 따라서 키 순서는 제공하되 현재 힙 조건은 unknown입니다. 이 누락을 완료된 힙 추론으로 보고하지 않습니다.
- 임의 비교자, 임의 합성 태그, 인코딩된 포인터, 관측되지 않은 종료 규약의 완전 지원은 보장하지 않습니다. XOR·OR 태그의 공통 연산 경로는 있으나 이번 실행 검증은 덧셈·곱셈·직접 대입과 OR 집계에 집중했습니다.
- 그래프 배치, 애니메이션, 화면 가독성은 검사하지 않았습니다. API 관계 검사 통과와 화면 완성을 동일시하지 않습니다.
