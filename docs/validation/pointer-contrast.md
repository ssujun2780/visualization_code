## 일반 배선과 포인터 배열의 대비 분리

2026-11-13 사용자 승인: 일반 포인터 배선은 평소 옅게 두고 필요한 관심 상태에서 강조하며, 자료구조 내부 연결선과 포인터 배열의 기존 구분 표시는 유지합니다. `presentation.md`, `visualization.md`의 연결선 구분, `animation.md`의 명령 시간선 보존, `ui.md`의 선택/호버, `pointer-wiring.md`의 기본선·선택 범위와 SS-03을 읽고 적용했습니다.

| 조항/요구 | 공통 변경 위치 | 검증 근거 | 남은 항목 |
