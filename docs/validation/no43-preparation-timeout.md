# No43 자료구조 재생 준비 시간 초과 조사

2026-11-13. 사용자 화면의 준비 시간 초과를 조사했습니다. **미해결**입니다. 이전 네 소규모 사례의 연결 성공을 No43의 준비 완료 근거로 사용할 수 없습니다.

## 실제 재현과 경계

현재 `examples/c/blind/No43.c`를 실제 세션 API 처리기와 실행/작업 분석 Worker로 한 번 실행했습니다. 셸의 루프백 제한 때문에 동일 미들웨어의 요청·응답 스트림을 사용했으며 실행·분석을 모의하지 않았습니다. 입력은 빈 표준 입력과 EOF입니다.

- API 응답: HTTP 200, 약 17.1초.
- 원본 실행: `completed`, 종료 코드 0, 진단 없음.
- 공개 중간언어: 29,474개 사건, 3,158개 객체.
- `workAnalysis`: 8초의 작업 분석 시간 제한 진단. `structureInference`가 전달되지 않았습니다.

원본 응답은 `test-results/no43-preparation/api.json`, 재현 코드는 같은 폴더의 `request.mjs`입니다. 과거 11,872개 사건의 기록 한도 조사와 구별합니다. 현재 실행은 정상 완료했습니다.

## 시간 초과가 이어지는 경로

1. `scripts/animation/work-analysis-client.mjs`는 자료구조 추론과 실행 관계 분석을 함께 수행하는 Worker에 기본 8초 제한을 둡니다. 시간 초과 응답에는 완료된 자료구조 추론 결과가 없습니다.
2. `src/animation/main.js`는 이 응답의 누락된 `structureInference`를 준비 Worker에 전달합니다.
3. `src/animation/prepared-worker.js`는 결과가 없으면 같은 원본 중간언어로 `inferStructures`를 다시 호출합니다. 서버 분석에 사용한 보조 관찰은 이 브라우저 입력에 포함되지 않습니다.
4. `prepare-playback.js`의 180초 제한은 추론과 표현 준비 전체를 합친 제한입니다. 어느 단계인지 구별하지 않고 “자료구조 재생 준비 시간이 초과되었습니다”라고 표시합니다.
5. 호출부는 모든 오류에 다시 실행 안내를 붙입니다. 같은 코드·경로에서 다시 수행하는 것만으로 이 병목이 해결된다는 근거는 없습니다.

따라서 현재 메시지는 C 프로그램의 비정상 종료나 입력 대기를 뜻하지 않습니다. 자료구조 표현 이력을 준비하는 단계에 도달하기 전에도 발생할 수 있습니다.

## 별도 단계 계측

생산 추론기를 수정하지 않고 `test-results/no43-preparation/probe/`에 현재 소스를 복사했습니다. 사본의 공통 단계 시작/종료에 시간 로그만 넣고, 같은 실제 API 응답에 보조 관찰 없이 추론을 적용했습니다. 부모 Worker가 45초에 강제 종료하도록 하여 장시간 작업을 남기지 않았습니다.

- 입력 복제/읽기 전용화: 약 1.1초.
- 배열 단계: 약 10.0초.
- 연결 단계: 약 1.7초.
- `ordered-tree-semantics`: 약 16.1초 시점에 진입, 45초 중단 시점에도 반환하지 않음.
- 이 계측은 `prepareStructures` 호출 전입니다. 표현 준비의 비용이라고 보고하지 않습니다.

전체 결과: `profile-stages.json`, 계측 사본 생성: `setup-probe.mjs`, 제한된 실행: `stage-profile.mjs`. 이 45초 조사로 전체 추론 완료 시간이나 브라우저의 180초 전체 경과를 측정한 것으로 주장하지 않습니다. 별도로 시작한 무계측 진단 실행도 중단했으며 완료 결과는 없습니다.
