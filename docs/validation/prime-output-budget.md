# 소수 코드의 출력 누락

2026-11-11. 원본 소수 판별 코드와 입력 `1 100`을 사용했다. C 코드·중간언어 생성 모델·추론기는 수정하지 않았다.

- 수정 전 웹 실행: 원시 관찰 한도 10,000, 공개 사건 5,120, 상태 limited, i=91 부근에서 중단. printf 호출은 2~89의 소수 24개에 대해 관찰됐으나 전달된 출력 사건은 `2\n` 하나였다. 나머지는 libc 버퍼가 종료 시 전달되기 전에 실행이 중단됐다.
- 공통 기본 한도로 별도 확인: completed, 종료 코드 0, 공개 사건 5,729, printf 25회, 2~97의 소수 25개 모두 출력. 버퍼가 전달된 뒤 기존 생성 모델이 실제 기록을 각 printf 호출에 연결했다.
- 수정: 실행 세션과 예제 API의 별도 maxEvents=10,000 옵션을 제거했다. 현재 ModelRecorder의 공통 기본값 100,000을 따른다. 다른 관찰 바이트·실행 시간 제한은 유지한다.
- 검증: `tests/animation-terminal-input.test.js`에서 입력값, 완료 여부, 25개 출력 각각의 callExecutionId·소스 행·호출/복귀 사이 위치, 각 출력 사건까지의 재생 상태를 독립적인 소수 목록과 비교한다. 관련 입력·예제 API 검사 총 10개와 Vite 빌드가 통과했다. 예제 전체를 재실행하지 않았다.
- 브라우저 자동 확인은 대규모 사건 목록을 조회하는 중 도구 시간 초과로 끝났다. 수정 후 화면 검증 완료로 간주하지 않는다.
