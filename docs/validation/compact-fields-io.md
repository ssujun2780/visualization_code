# 작은 기본 상자와 전체 입출력 필드

2026-11-11. 사용자 정정에 따라 기본 상자·일반 필드를 줄이고 입력·출력 필드는 키웠습니다. 출력은 실행 공간 안에 모두 보관하며 높이를 넘으면 내부 스크롤로 확인합니다. 알고리즘 추론기·자료구조 추론기·중간언어 생성 모델은 변경하지 않았습니다.

읽은 계약: `presentation.md`, `visualization.md`의 공간·대상 및 연결선, `ui.md`의 실행 조작, `pointer-wiring.md`의 경로 보존·컨테이너 선택, 실행 관계 R-02~R-05. 기록된 출력 시점·선택된 스트림·현재 실행 상태는 보존합니다.

검증 전 기대: 소수 1~100 예제는 `2`부터 `97`까지 25줄을 모두 보관하고, 처음과 마지막으로 스크롤할 수 있어야 합니다. 작은 상자에서도 필드 포함 관계와 접기·포인터 연결을 유지해야 합니다.
