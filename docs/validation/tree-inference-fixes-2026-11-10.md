## 당시 발견한 생성 모델 문제 — 후속 작업에서 해결

추론 보완 당시 `tests/ir-inference-common-boundaries.test.js`의 내장 정수 배열 재귀 예제가 평가 순서 변환에서 실패했습니다.

```c
typedef struct { int z, c[2]; } R;
R q[4] = {{3,{1,2}}, {5,{-1,-1}}, {7,{-1,-1}}};
int f(int k) {
    if (k < 0) return 0;
    return q[k].z + f(q[k].c[0]) + f(q[k].c[1]);
}
```

진단은 `evaluation-order-unresolved`, `필수 값 의존성을 거스르는 순서입니다.`입니다. **추론을 비활성화한 실행에서도 같은 실패가 재현**됩니다. 분리된 `l`, `r` 필드 구현은 통과합니다. 이번 추론 변경으로 고치거나 검사 기준을 완화하지 않았습니다.

후속 사용자 요청으로 생성 모델의 의존성 우선 정책과 주소 계산 분류를 수정하여, 이 검사는 기대값 그대로 통과했습니다. 원인·수정·최신 검증은 [평가 순서 보완 기록](evaluation-order-dependencies-2026-11-10.md)을 참고하십시오. 아래 증거는 최초 추론 작업 당시 기록입니다.
