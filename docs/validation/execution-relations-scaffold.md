# 실행 관계 추론기 뼈대: 설계 대응표

이 문서는 판정기가 비어 있던 최초 뼈대의 검증 이력입니다. 후속 호출·구간·복사 판정기 구현과 현재 검증은 [초기 공통 규칙 검증](execution-relations-rules.md)을 따릅니다. 빈 판정기 목록의 `not-implemented` 계약 검사는 유지합니다.

2026-11-11. 사용자 요청은 새 추론기의 뼈대만 만드는 것입니다. 중간언어 생성 모델·자료구조 추론기·기존 실행 세션·재생기·배치는 변경하지 않았습니다. 새 추론기는 기존 파이프라인에 자동 연결하지 않았습니다.

## 적용 계약과 사전 기대

실제로 확인한 문서: AGENTS.md, presentation.md, execution-relations.md의 R-02/R-04/R-07·W-01/W-02/W-03/W-06/W-07, inference-model.md의 의존성/읽기 전용 경계, design-implementation-template.md.

검증 전 기대: 판정기 0개이면 미구현 상태이며 관계는 비어 있어야 합니다. 기록·객체·값·사건 순서를 바꾸지 않고 다른 실행의 입력은 거부해야 합니다. 검증용 합성 관계의 미래 근거·범위 오류는 거부하고, 판정기 실패는 부가 결과에만 남겨야 합니다. CLI는 저장된 기록에서 별도 결과만 써야 합니다. 실제 관계 인식률이나 화면 가독성은 이번 완료 조건이 아닙니다.

| 조항 | 변경 위치 | 검증 근거 | 상태와 남은 항목 |
| --- | --- | --- | --- |
| R-02, W-01 | execution-relations/index·engine·worker.mjs | 생성/구조/화면 코드 import 금지 검사, 원본 JSON 전후 동일, 독립 Worker·시간 초과 진단 | 뼈대 구현. 기존 파이프라인 연결 없음 |

| R-04, W-03 | index.mjs의 조회 생성기 | 사건 배열 순서 기준 근거 시점 검증, 이전 시점에서 숨김, 조회 결과 변경 격리 | 기본 성립 시점 필터 구현. 후보의 역사 버전·증분 처리 미구현 |

| R-01, R-03, R-05, R-06, W-04/W-05 | 변경 없음 | 이번 화면 검사 없음 | 동시 보기·구간 표현·재귀 배치·시각적 오류 추적은 미구현/미검증 |

검사는 `tests/execution-relations-scaffold.test.js`만 수행합니다. 저장된 스칼라 IR로 입력 계약을 확인하고, 합성 관계·판정기로 검증 경계와 실패 격리를 확인합니다. 합병정렬 등 예제 C를 다시 컴파일하거나 실행하지 않았습니다. 합성 관계가 나왔다는 사실을 실제 추론 성공으로 세지 않습니다.

결과: 해당 검사 9개 통과. CLI도 임시 폴더의 기록으로 실행했습니다. 실제 판정기와 화면 연결이 없으므로 관계 인식 성공이나 시각화 검증 완료로 보고하지 않습니다.

이 대응표는 구현 변경의 근거 문서이며 자동 설계 준수 검사기를 완성했다는 의미가 아닙니다.
