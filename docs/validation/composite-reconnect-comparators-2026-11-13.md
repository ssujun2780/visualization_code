## 기대값과 실제 결과

새 비교 예제의 기대값은 실행 전에 코드에서 정했습니다. 첫 필드 오름차순·동점 필드 내림차순, 반대 판정은 반대 순서, 구성원 4개, 부모/자식 간선 3개, 루트 변경 전 정상·변경 후 위반입니다. 포인터 인자, 구조체 값 복사, 삼항식, 단계별 상수 반환, 논리식, 보조 함수 전달을 같은 검사로 확인했습니다.

첫 검사에서는 비교 순서가 맞아도 사용 범위가 빠졌고, 접힌 음수 상수를 놓쳤습니다. 사용 범위는 원소 전체 READ만 찾던 경로에서 함수 안의 필드 READ와 인자 복사 근거를 추가해 해결했습니다. 음수는 실행 기록의 compiler-folded 상수, 합쳐진 부정·비교는 AST 직접 감싼 비교와 실제 입력으로 해석했습니다. 검사 기준이나 원래 예제의 기대값은 낮추지 않았습니다.

추가 반례는 동점 경로 미실행, 같은 숫자의 다른 반환, 산술 변형·축소된 반환, 양수 표본에서만 값이 같은 signed→unsigned 키 변환입니다. 의미가 바뀔 수 있는 키 변환을 원래 키 순서로 확정하지 않습니다.

## 남은 경계

임의의 사용자 비교 함수를 실행하거나 수학적 의도를 추정하지 않습니다. 관측하지 않은 분기, 키 자체의 임의 산술 변환, 별도 외부 함수 의미는 완전한 비교 정책으로 보장하지 않습니다. 재연결에 필요한 구성 근거가 없거나 여러 대응이 있으면 원래 지정과 진단을 보존합니다. 이러한 경우를 원래 목표에서 삭제한 것이 아니라 현재 보수적으로 남기는 경계로 명시합니다. UI 연결·실제 화면 가독성·애니메이션 검증은 이번 범위 밖입니다.
