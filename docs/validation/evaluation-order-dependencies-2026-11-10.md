# 필수 의존성 우선 평가 순서 보완 — 2026-11-10

## 원인과 수정

전역 구조체 배열의 `q[k].c[0]`에서, 소속 미확정인 중간 주소 계산을 건너뛰어 마지막 주소 계산을 `q` 피연산자의 평가로 잘못 분류했습니다. 이후 선호 방향을 먼저 결정하고 SSA 충돌을 변환 실패로 처리하던 정책 때문에 정상 코드를 실행하지 못했습니다.

`scripts/model/evaluation-order.mjs`와 `scripts/model/compile.mjs`를 보완했습니다.

- 관찰 메타데이터가 없는 LLVM 보조 명령까지 정의·사용 관계를 따라가며 후속 주소 계산을 식의 입력 평가와 구분합니다.
- 필수 SSA 의존 간선을 먼저 구성하고, 준비된 피연산자 구간 중 선호 방향에서 앞선 것을 선택합니다. 독립적인 나머지 구간은 계속 정렬할 수 있습니다.
- C의 필수 순서·선택은 보존합니다. 구간 교차, 후속 소비자 포함, 외부 제어 흐름 등으로 이동을 증명하지 못하면 해당 구간을 유지하고 제외 사유를 남깁니다. 이 사유 자체로 변환을 실패시키지 않습니다.
- 선호 순서와 실효 순서를 구분하여 기록하고, 실제 적용 순서의 의존성을 검증합니다. UI에서 사건을 재정렬하지 않습니다.

## 검증 결과

기존 기대값을 유지했습니다. 추론기·계측기 변경 없이 평가 순서 관련 검사 17개와 원래 실패했던 검사 1개가 모두 통과했습니다. 전체 예제와 전체 테스트 묶음은 실행하지 않았습니다.

원래 실패한 코드는 좌→우와 명시적 우→좌 모두 정상 종료하고 `15\n`을 출력했습니다.

| 정책 | 실제 `f` 호출 인자 순서 |
| --- | --- |
| 좌→우 | `0, 1, -1, -1, 2, -1, -1` |
| 우→좌 | `0, 2, -1, -1, 1, -1, -1` |

두 실행 모두 `irGaps`와 미설명 관찰은 빈 배열입니다. 관련 검사에서 원시 관찰의 호출 순서와 공개 중간언어 호출 순서도 비교했습니다.

일반 배열, 구조체 필드, 구조체 안 배열의 상수/변수 첨자, 포인터 매개변수, 중첩 구조체, 이차원 배열의 7개 컴파일 변형이 모두 통과했습니다. 기존에 거부되었던 두 형태도 불필요한 LLVM 재배치 없이 통과했습니다.

LLVM 수준 검사에는 피연산자 사이 값 의존성, 의존성에 따라 원래 순서를 유지하는 경우, 독립 구간만 이동하는 경우, 교차·외부 제어 흐름, 관찰 메타데이터가 없는 주소 변환을 포함했습니다. C 실행 검사에는 중첩 호출, 전역 상태 변경, 주소 계산의 부수효과, 단락 평가, 조건식, 쉼표, 반환 및 구조체 ABI를 포함했습니다.
