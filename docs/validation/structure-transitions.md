# 자료구조 변화의 공통 표시 경로

2026-11-14. 사용자 승인 계획의 구현 및 검증 기록입니다. **코드·빌드 검사는 통과했으나 실제 브라우저 1배속 화면 검증은 도구 정책으로 완료하지 못했습니다.** 전체 작업의 화면 검증까지 완료했다고 간주하지 않습니다.

## 범위와 계약

실제 읽은 문서: `AGENTS.md`, `presentation.md`, `prepared-scene.md` PS-02·06, `structure-shapes.md` SS-01~04, `structure-visualization.md` SV-01~04, `animation.md`, `visualization.md`, `ui.md`, 기존 배치/수동 수정 경로. 고정 구조 종류·물리 슬롯과 모든 계층 노드 좌표 고정을 구별하도록 최신 사용자 합의를 ST-01~05로 기록했습니다.

시각화 준비·배치·재생 소비 경로만 변경했습니다. 중간언어와 자료구조/실행 관계 추론 경로 184개 파일의 작업 전후 SHA256이 모두 같습니다(`test-results/structure-transitions/protected-check.json`). 특정 함수명·변수명·예제 번호·출력에 대한 분기를 제품 경로에 추가하지 않았습니다. 명시적 자료구조 종류와 이미 제공된 역할만 사용합니다.

검증 전에 기대한 조건: 현재 부모가 자식보다 위에 배치되고 색만 바뀌면 좌표 유지, 중간 순환/공유 연결을 자동 수정하지 않음, 배열 힙의 슬롯 유지, 다중 키 관리 필드 분리, 같은 노드 ID/범위와 실제 출처 유지, 보간된 그림과 클릭·연결점 일치, 탐색/수동 고정과 기본 journal 불변입니다.

## 실행한 검사

관련 공통 경로 **113개 통과, 실패/건너뜀 0개**. 기존 C 예제 전체는 실행하지 않았습니다. 로그: `test-results/structure-transitions/focused-tests.log`.

- 새 `animation-structure-transitions.test.js`: 현재 관계·색·배치·임시 불완전 연결·물리 슬롯·개별 할당·키 역할·상태·보간/클릭·포인터 끝점·원본 불변.
- 기존 모양/고정 표현/준비 캐시/표시 이력/배선/도구/선택/재생 경계/반복/트리 대비/공간 검사.
- 빌드 통과(`build.log`). 기존 편집기 큰 청크 경고는 남습니다.

실제 C 입력 `tests/fixtures/structure-transition-view.c`는 정상 종료하며 71개 원본 사건을 기록했습니다. `scripts/animation/prepare-transition-check.mjs`는 실제 컴파일러의 멤버 offset/stride와 시점별 메모리·포인터 관측을 읽어, 명시적으로 주어진 역할의 소비자 확인 자료를 만듭니다. 저장 위치는 `test-results/structure-transitions/view-recording.json`입니다. 색·방문 역할을 이 QA 자료에서 명시하므로 추론 정확성을 검증한 결과로 사용하지 않습니다. 생산자 출력을 예상 화면/좌표에 맞춰 고치지 않습니다.

## 실제 화면 검증 중단

1배속 검증을 위해 새 빌드를 열었으나 내장 브라우저의 localhost 연결이 시간 초과되었습니다. 서버가 표시한 실제 주소에서도 연결을 완료하지 못했습니다. 대체 Firefox 제어는 도구가 ‘현재 Windows 브라우저에서 URL 정책 검증을 지원하지 않는다’는 이유로 중단했습니다. 정책을 우회하거나 다른 자동화 기술로 브라우저를 제어하지 않았습니다. 실제 화면 스크린샷·1배속 가독성 성공 근거는 없습니다. 로컬 화면에서 색 변경·연결/위치 보간·주변 연산의 동시 관찰과 수동 배치 후 탐색을 마저 확인해야 합니다.

검증 과정의 모든 인터페이스 바인딩 서버는 임시로 사용 후 종료했습니다. localhost 전용 preview는 포트 5176으로 남겨 두었습니다. 준비된 자료는 화면의 ‘실행 기록 열기’로 열 수 있습니다.

## 남은 범위

자료구조별 회전/분할/병합 이름과 원인 해설, 모든 알고리즘의 방문/확정 역할 자동 판정, 사용자 역할 편집 UI, 대규모 최악 성능/메모리와 모든 구현의 가독성은 완료 항목이 아닙니다. 구조·상태·색의 근거가 공급되지 않으면 표시에서 임의로 만들어 내지 않습니다. 실제 브라우저 1배속 확인은 이번 작업의 미완료 검증 항목입니다.
