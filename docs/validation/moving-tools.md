2026-11-12. 알루 작업대를 현재 데이터 가까이 옮기는 화면 변경입니다. 중간언어 생성 모델과 자료구조·작업 관계 추론기는 변경하지 않았습니다.

## 적용 계약과 범위

실제로 확인한 문서는 `presentation.md`의 모델·추론 경계, `animation.md`의 기본 원칙·도구, `visualization.md`의 공간 배치, `ui.md`의 직접 조작 규칙입니다. 세부 적용 계약은 `moving-tools.md` T-01~T-05입니다. 기존 고정 작업대를 현재 입력을 따라가는 작업대로 변경했습니다.

검증 전 예상은 다음과 같습니다. 지역변수와 멀리 떨어진 힙의 계산을 번갈아 선택하면 도구가 해당 데이터 가까이 이동하고, 원래 상자와 입력·출력 필드는 이동하지 않아야 합니다. 같은 CALC와 결과 WRITE·완료 분기는 도구 위치를 공유해야 합니다. 직접 드래그하면 자동 이동보다 수동 배치를 우선해야 합니다.
